## 结构零漂移清单
| 原图组成 | 本轮实现 |
|---|---|
| 状态栏/返回/标题/右上系统示意 | 原布局保留 |
| 一行搜索+地图 | 原布局保留 |
| 三等分「全部区域 / 全部容量 / 全部租期」 | **严格三栏**，不额外加入距离排序/服务筛选/需求栏 |
| 门店 A 图片 → 名称 → 3 标签 → 地址 | 原顺序保留；距离在**地址原行**右侧微增 |
| 门店 A 两条仓型（容量 + 月价 + 文字用途 + 立即下单） | 原两行，不增加“预览”标题与折叠/查看更多 |
| 门店 B 图片 → 名称 → 3 标签 → 地址 | 原顺序保留；距离同上 |
| 门店 B 两条仓型 | 原两行，不增加中间区块 |
| 图片裁切与布局 | 来源 A 原图中的两张照片，不重新生成外观 |
| 背景 | `#fff`，用户明确批准 |

**禁止项检查：** `store-preview-heading`、额外“参考价说明行”、需求提示层、收起/展开、第四栏筛选、查看更多、动态 JS 店价/仓型适配、额外组件数量均为 0。本阶段静态按钮不声明具备真实下单交互。

## 实际浏览器 QA（容器内 headless Chromium）
- 设计原宽：358×812，布局与用户提供 A 手机裁图在同尺寸并排测量。
- 375×812、390×844：两个响应宽度等比例缩放原 358 视觉几何，避免样式断点改变版式。
- 每个尺寸 **2 家门店、4 条仓型、0 个额外结构、2 张图片全部加载、0 JS 错误、0 横向溢出**。三尺寸结构 QA：**3/3 PASS**。
- 原图与当前 358 截图全图 RGB MAE 为 **23.0/255**（包含允许新增的公里数、浏览器字体渲染、设备图标、颜色及少量边框差异）；照片区域分别约 **29.2/255** 与 **20.4/255**。这不是像素无差异，不能把“零结构漂移”误称“100% 像素一致”。
- 容器生成叠图、差异热力图、375/390 viewport/full PNG、QA JSON 都随本次独立静态交付 ZIP 提供，并未作为图片二进制提交本 PR。
