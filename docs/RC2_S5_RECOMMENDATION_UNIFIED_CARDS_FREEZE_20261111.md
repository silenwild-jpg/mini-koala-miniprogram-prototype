# RC2-S5-DECISION-FREEZE-01｜S5需求摘要、双实体门店＋考拉E存与跨页卡片契约

**决策日期：2026-11-11｜用户直接裁定 + UX评估补充**

## 用户已明确裁定（覆盖全部历史冲突版本）

1. **删除并冻结全部“对比”功能**：移除S5推荐区“对比/对比费用”按钮、双门店对比浮窗、双列比较表与相关事件/状态/测试；全站未来评审、视觉探索、PRD和新版用户界面不得再建议恢复对比功能。允许针对**单个仓位**查看本仓费用明细，不应称为对比。历史02C/02D和PR98中任何方案B的对比能力均正式废弃。
2. **S5顶部合并容量＋租期**：已确认需求显示为一条简短的「用仓需求 3m³ · 12个月    [修改]」，合并原两块存储需求与租期选择，不再出现两个分别修改入口。点唯一修改入口回CAP等原需求编辑路径，保持容量/租期变更后S5刷新。S5并非全部入口必经CAP；仍需保留空容量/未确认租期的补填态，不能虚构已确认值。
3. **用仓位置一整行可点**：定位图标＋实际位置文字/手动状态＋右侧chevron或定位图标作为一个44px高以上触控热区，不再额外展示“修改”按钮。点击调用地图选点能力；真实小程序端应通过授权位置或地图位置选择，用户拒绝定位时允许手动选城/区域，不能阻断流程。网页原型中如未接原生地图能力必须明确使用可执行的选址降级方案，不可伪称原生组件已接通。
4. **默认推荐结构**：实体仓位第一张最近、第二张近范围低价（有可核验真实低价时；否则仅作为第二候选），**考拉E存作为独立服务推荐位紧随两张实体卡**。考拉E存不参与实体门店排序，不显示实体门店距离、库存、默认仓位信息。S01的考拉E存第三位固定规则与S5的独立服务位不是同一个实体卡排序机制。
5. **每家门店只显示1个当前最匹配仓位**：默认不展开第二仓位，不出现“另有1种仓位可选”入口，删除S5中主动列举/切换次选仓位的逻辑。需要查看更多仓位时通过已存在的“查看更多仓位”进入S01、或进入门店详情S02；携带需求条件。原先02D/03A次选仓位入口方案被本次裁定替代。
6. **默认仓位不标“独立仓”**：默认就是单个仓位，仅显示容量，如“3m³”。只有真实由多个仓位组成的组合方案，才显示“组合仓”并按已有合同提示。
7. **整期租金＋月均在同一价格模块**：整期主价、月均次级紧邻，同一块信息，不隔着仓位说明/按钮/其他分区；押金/50管理费和首次应付可在当前方案的一店费用明细展示；不得恢复双门店费用对比。
8. **门店操作图标化与减少文字**：门店主图片/店名可进入S02，地图导航采用可识别图标，保持44×44热区、无文字“查看门店/导航”双出口污染；图标应有屏幕阅读器描述和有效点击反馈。
9. **H01/S01/S5跨页同源、同视觉语言，非逐像素相同**：门店ID、店名、真实图片、位置与距离口径、服务标签/优惠事实采用同源数据；同城市同位置同门店距离一致；相同仓位/租期的整期租金与月均一致。H01/S01展示公开门店最低立方米单价，S5展示匹配具体仓位折后整期价，**不同价格指标不可要求数值一致或混作同义**。统一品牌色、排版、图标、图片裁切比例和操作语义；H01横滑卡、S01高密列表、S5推荐卡有各自适宜的几何尺寸，禁止强制完全同高/同宽。
10. **推荐角标**：不继续把“距离最近”和“区域低价”当成额外的醒目独立首行；第一优先用真实距离与排序位置表达，第二必须经低价数据验证才能标注；考虑将低价弱标识整合在价格区域，不占用店名行和门店图片；不得将“3km内低价”等绝对承诺写在UI。
11. **价格显示压力上限**：设计测试整期租金最大¥100,000；首次应付含押金和管理费可以更高，不把¥100,000当成自动的计价代码硬封顶。
12. **防回退与验收**：375×812/390×844，至少12px辅助字号、44×44点击热区、无横向溢出；S5两家卡+E存默认；无匹配/单店/拒绝定位/未确认租期/组合仓/顾问触发/返回修改仍有完整状态；O01/价格/手机号/真实支付与CRM边界保持。用户未正式签收前不归并PR#96、不更新UAT、不改main。
