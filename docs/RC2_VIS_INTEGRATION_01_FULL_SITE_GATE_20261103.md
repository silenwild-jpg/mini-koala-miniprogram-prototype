## 3. 门店图资产门禁
PR57报告14张用户JPEG中精选12张，对应12个SIM_*演示门店，每店1张512×512卡图和1张1152×720详情图，共24 WebP约0.835MB；manifest登记源片与衍生品SHA、裁剪框、identity_verified=false。此组图片是演示图位匹配，不是物理门店拍摄地点的证明。
- H01和S01使用同store_id的card图，S02使用同ID的hero图；不可将图源按列表序号轮换。
- 需要打开同一版本的375/390全屏截图逐店查看裁剪是否截断门头/标识、倾斜、过亮/过暗、图片拉伸、比例不一、加载回退和404。
- H01的冻结英雄图、品牌证据图、导航图不受替换；禁止借换图重建卡片层级。
- 未核实实景归属时，内部演示可使用；对外或真实上线应核验门店身份/授权。

## 4. 不可跳过的产品一致性门禁
1. S01 顶部只能显示排序、距离、服务；价格优先只能在排序中，不能隐藏价格筛选状态。
2. U01为退役页面：S01/S02/S5仓位卡可直接进入O01；旧U01链接安全返回，不携带旧报价/订单快照。
3. 基础浏览不强制手机号；正式报价与下单前有效验证，拒绝/关闭不能绕过；既验证不重复打扰。
4. 价格使用整期主价、月租次级；不出现“参考价”；不编造地址、公里数、库存、服务优惠资格。
5. 单仓与组合仓的收藏、轻量对比、顾问规则一致；不得因视觉模板丢状态。
6. H01必须沿用批准VIS-11J视觉主结构，S01高保真卡片主体不被旧低保真代码覆盖。
7. 审计通过需要：同一commit+相同SIM数据+375×812及390×844全页截图+交互录屏/浏览器输出+人工逐区验收。
