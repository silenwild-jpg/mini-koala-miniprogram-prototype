# VIS-SYSTEM-04A-S5｜月租与租期表述定向修复

2026-11-11，PR [#101](https://github.com/silenwild-jpg/mini-koala-miniprogram-prototype/pull/101) 独立分支。仅更改页面展示文案与浏览器断言，不变更 `demo-core.js` 的费率、订单快照或真实支付。

## 原因
- S5推荐仓位副价调用 `presentation.price().average`，显示「月均约 ¥…」，违反当前去“月均”及展示具体月份规则。
- 同一桥接文件中的快捷下单、费用详情和O01辅助说明也存在「月均约」「券后月均约」。
- 当前分支 `demo-core.discountedMonth` 仍四舍五入到小数2位；未完成“整元截断月租×租期=整期整数租金”的全站价格底座迁移。这是**已经查明的计价合同冲突**，不允许仅由UI把小数截掉并显示错误乘积。

## 本次定向修改
1. 在`br04/bridge.js`引入`rentFormula(a, months)`，显示真实已计算月租 `¥x/月 × N个月`，仅当 `月租×月份` 与中央`rent_total`在1分误差内相符时显示乘号。意外不符时不显示虚假的乘法关系；有小数时仍保留实际小数，等待中央整元计价改造。
2. S5推荐仓位不用`p.average`，改用同源`p.amounts`和租期；快捷下单与O01复用同一个明确月租定义。
3. 费用明细原「月均约」改「月租」；O01优惠券之后只显示「券后整期租金」，不把整期租金优惠均摊并假称每月账单金额改变。
4. 新增37月边界浏览器场景；补充`月均`文案禁用及“×月份”公式精确相符时才可展示的校验。

## 门禁
本补丁可验证“无月均文案、月租来源准确、未误称券后每月付费”；但**全站整元/整期精度不能宣布PASS**，直到中央计价统一规则覆盖PR#101并对S5/O01/续租/券后价同SHA复测。本项目仅为演示原型，不进行真实售价、销售折扣真实性或后端支付验证。用户视觉终签及跨页合并继续HOLD。
