# RC2-PUBLIC-PRICE-01｜H01/S01/S02 公开月租起价及估算回流统一

日期：2026-11-12。产品指令：S02 和 S01 未填写需求时使用**当前最优惠租期档位对应的折后月租起价**，消费者界面仅用「起」表达，不用「参考」；估算工具提交时容量和租期必须同时完成确认，再返回原入口。不能假设有“只选容量、未选租期”的正常估算回流状态。

## 页面规则

| 页面及状态 | 显示内容 | 数据来源 |
|---|---|---|
| H01 首页门店公开卡 | ¥X/m³/月起 | 门店可租仓位中最低折后月租 ÷ 对应仓位容积。与 S01 共享来源 |
| S01 无需求 | ¥X/m³/月起 | 同 H01。浏览态第一/第二门店卡可直接进 S02，第三位考拉E存不参与仓位最低价 |
| S01 已确认需求 | 匹配仓位整期租金及月租×已选月份 | 核心具体仓位报价；容量、租期双确认 |
| S02 无需求 | 每个仓位 ¥X/月起 | 该仓位按现行最优惠租期档位的折后月租 |
| S02 已确认需求 | 各可选匹配仓位的整期租金及月租×已选月份 | 核心仓位报价；容量、租期双确认 |

- 所有“起”价按 **当前可租库存、原价、现有 termRules 折扣阶梯** 动态算出；不让库存不足或售罄仓位压低公开价。2026-11-12 演示表最优惠 37–60 个月 5.5 折；未来修改折扣表时自动取最低因子对应档位，不把 37 个月硬编码为页面规则。
- 计算继续使用核心每仓租期折后月租取整逻辑；不改押金、管理费、优惠券、整期价、手机号验证、订单快照或下单校验。
- 页面不出现“12个月参考”、“租期待确认”、“已选容量但没选租期”等默认状态文案。价格“起”不暗示租期已经选定，正式价格仍由用户完成容量＋租期后计算。
- CAP / ITEMS 估算流程必须完成容量、租期双条件后才能提交返回；S5 仍强制此守卫。少见的历史/异常不完整草稿在 S01/S02 仅按普通浏览处理，不作为新产品正常状态，也不允许绕过 O01 必选校验。
- 不添加促销划线比较价、信息解释卡、边框、标签或 UI 备注。不改页面布局和 S01/S02 视觉母版。S02 交通路线/电话/地图及 E 存、组合仓规则不变。
- 首页 H01 的公开门店起价自动同步，因为原本就与 S01 使用同一 presentation.cubicReference()。仅同步数字计算，不在本任务改其结构和设计。

## 价格与演示边界

- S01 单位是 ¥/m³/月起，S02 是 ¥/仓/月起：数据来自同一仓位最低折后月租，但**计量单位不相同**。不得直接比较两者数值大小。
- 36→37个月整期价格倒挂是既存 [Issue #106](https://github.com/silenwild-jpg/mini-koala-miniprogram-prototype/issues/106)；现阶段演示价表未获业务重新裁定，本任务不改变费率。最低月租起价属于明确批准的演示展示规则，非真实商业广告合规批准。
