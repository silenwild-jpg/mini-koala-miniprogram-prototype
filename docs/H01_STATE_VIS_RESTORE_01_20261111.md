## 逐状态恢复契约（当前是建议，尚未编入 UI）

| 业务阶段 | 第一视觉重心 | 建议保留 | 建议收敛 |
|---|---|---|---|
| 新客 / 历史结束 | 完整找仓母版 | 双任务入口、三推荐、场景、企业、品牌、底栏 | 不添加重复搜索或营销卡 |
| 估算 / 已选仓 | 已保存需求、继续选仓 | 容量、租期、唯一主按钮 | 避免多套同义浏览入口 |
| 预约留存 | 预约状态及办理进度 | 查看预约、服务入口 | 合并重复门店入口 |
| 待支付 | 首次应付、03:00:00 和继续支付 | 门店仓位、租期、费用明细 | 不恢复无关营销内容 |
| 支付失败 / 超时 | 原订单失效及新下单 | 仓位已释放、重新选择仓位 | 不允许旧单再次付款 |
| 待验证 / 待入仓 | 身份门禁条件、起租时间、门店位置 | 身份验证、入仓指引、导航与存取时段 | 不展示无关促销 |
| 在租 | 仓位、到期日和存取 | 正确的存取时间、位置/帮助、租约 | 低频加租/换仓收折，A/B 入口待视觉终签 |
| 临近到期 / 续租中 | 续租及进度 | 当前仓位、到期时间、续租操作 | 不重复续租按钮 |
| 退租 / 退款 | 验仓或押金进度 | 联系门店、处理事项 | 不以营销替代售后 |
| 多订单 | 当前最高优先级任务 | 其他订单轻量入口 | 不堆叠多张重卡 |

**视觉主张**：保留同源品牌头部、字体、价格层级和底部导航；任务模式可以隐藏营销，但不应把“单一卡片＋大块空白”自动视为最终签收母版。不要为了填满空白添加多余容器和装饰。
