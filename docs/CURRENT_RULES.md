# 现行规则（2026-10-23受控摘要）

本文件是 Codex 迁移前的防漂移条款；完整原始审批记录仍由项目资料及各分支冻结文件界定。

1. 默认首页遵守10月23日批准VIS-11J；底栏第三项仍标“预约订单”，点击后轻量操作层分“预约用仓”“立即下单”。
2. 预约用仓只创建销售线索，不创建订单；立即下单在填写门店/仓位/用仓时间等必要字段后进入O01。
3. 用户在CAP直接输入容量为主；不用已废止的四档卡片作为默认选择。按物品估算、AI估算、顾问选仓为辅助分支；最终汇入S5（涉及顾问旧成功页需更新）。
4. 容量及租期是否确认必须按用户操作状态判断，不可静默默认12个月；S5必须继承已确认的容量与租期。
5. U01仓位详情从最新链路删除；S02仓位卡可直接进入O01；不得自动恢复旧U01必经路径。
6. S01/S02与O01共用中央真实演示目录ID，不得将分支中四个旧上海门店强行映射为中央门店。选择变更后，旧仓位/价格快照失效。
7. 组合仓维持一主单，押金按各仓一月租金汇总，管理费整单收一次¥50；单仓和组合仓订单快照模型不得混用。
8. 价格、租期、开始日期等关键字段由中央校验与签发快照。S5“整期租金”是主视觉、“月租”为次级。
9. 新签主链可演示：H01→S01/S02→O01，或CAP/估算→S5→O01，或快捷下单→O01；预约分流仅销售线索。
10. 维持VIS-GUARD，禁止旧原型污染获批视觉，不开展当前范围外的正式生产交付。
