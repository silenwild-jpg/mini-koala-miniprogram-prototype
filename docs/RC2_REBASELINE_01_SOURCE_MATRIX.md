## 4. 本期裁决的冲突覆盖

1. **覆盖 PRD V1.0** 中“预约用仓地址必填、手机选填”：改为**手机+用仓地址必填**，咨询仍独立。
2. **明确押金**：不再允许“标准月租/月均”两可口径；必须按**租期折扣后月均**。单次优惠券不反算押金是本基线的保守实施解释，接受财务政策复核。
3. **明确公开价格**：门店的每立方最低单价，不是单个匹配仓位月租。用户已有需求时则改为实际匹配仓位的租期折后月租×月份。
4. **推荐权重**：可租库存是硬约束，距离是主排序信号；低价是适当范围内的辅助比较；E存及运营位单独说明。
5. **组合仓**：允许同店不同规格组合、租金逐仓累加、押金按组合折后月均、单次50元管理费。
6. **企业**：共享个人业务商品/仓位库存与价格服务，仅线索/客户分群独立。
7. **存取时段**：现阶段可用模拟值；真实开发需运营核实，不可当成已实现的真实门店服务。
