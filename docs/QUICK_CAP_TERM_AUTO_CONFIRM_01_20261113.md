# QUICK-CAP-TERM-01｜2026-11-13 最终容量/租期合同

## 有效规则

- **快捷下单（QUICK）**：用户必须选择有效可租的单仓或组合仓；选中后**自动将仓位总容量写入共享需求容量**，视为容量已确认。**租期必须由用户主动选择**，不得自动预选12个月，也不得允许容量/租期缺失进入O01。
- 从 CAP/ITEMS 继承已有容量需求时，选择的仓位需要满足原需求；**不允许**自动改写用户已经手动确认的容量。只有来自QUICK选仓的容量随该仓位变更而更新，原来主动选中的租期继续保留。
- 预约用仓（BOOKING）：容量、租期为**选填**；地址和联系电话依旧必填。用于收集线索，暂不产生订单。
- S5：独立规则，必须已经确认容量+租期；本变更不得放松S5或`core.setTerm()`校验。
- O01：继续由既有验证、用仓日期、报价签名、库存、隐私/服务协议勾选等守卫管控。
