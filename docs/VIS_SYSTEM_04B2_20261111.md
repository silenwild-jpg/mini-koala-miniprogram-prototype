# VIS-SYSTEM-04B2｜中文字体375/390实际渲染验收

2026-11-11。**来源基线 PR #120**，新隔离候选。目标是对中文文字、价格与标签实际渲染进行二次技术验收，不修改业务规则、结构或已确认视觉母版。

## 验收要求
1. 原型仍为演示应用，可使用虚构促销、门店和公里数，不检查任何真实经营数据。
2. 由单一受测SHA生成H01、S01、S02、S5的375×812及390×844页面截图；保留仓号、容量、价格和标签的既有布局。
3. GitHub原先的截图因托管运行器缺失中文字体而为方框，不能算中文视觉通过。本轮尝试**在运行器中临时安装**开放许可的字体（优先系统包，必要时从公开字体仓库取得用于CI渲染），**不将字体加入源码/下载包/用户附件**。安装失败即HOLD，不得伪称通过。
4. 截图前验证`fc-list :lang=zh`存在中文字体，并用真实Chrome Canvas测试“仓/中/考/测”与缺失字形的像素指纹互不相同；检查标签实际11px、同名标签语义色、主要价格及按钮文字无非省略号裁切。超长地址等历史有意省略的文本不贸然视为bug。
5. 以五城标签分类、整期计价、H01状态Node回归作护栏；一旦发现真实中文字宽导致溢出，只允许CSS局部定向修复，不重新绘制结构。
6. CSS像素验收在Chrome+CJK代理环境进行，不自动等于微信真机/PingFang的最终视觉终签，PR仍Draft/HOLD、NO MAIN MERGE、NO DEPLOY。

本轮落地证据须记录Action链接、受测SHA、所有PNG/JSON及具体遗留风险。
