## 本次实际改动

1. account.html/account.js：旧服务详情继续复用同一个 sessionStorage 共享状态，但默认用户入口转为「个人信息」，内置订单多状态预览只在显式 debug 模式下可见。移除重复「我的主页」右顶栏。验证身份后提供入仓操作；未验证提示先验证，已验证但未起租不显示可操作开门按钮。联系人和手机号是两种状态，手填联系电话仍不算已验证。
2. m01-service-shell-02.css：仅影响 account.html，使用与 M01 相同的绿色、轻分隔线、48px 操作控件及固定四导航，降低旧子页面卡片化。
3. lifecycle-ui.js + m01-lifecycle-shell-02.css：对 RN01/EX01/DP01/IV01 增加同订单的门店/仓位/租期/状态摘要；RN01 不默选三个月、保留草稿和中央范围校验；退租日期不得早于演示业务当前日期；押金状态采用中央实收押金金额，不另算。
4. app.js O03：按生命周期决定订单服务可达性，active/upcoming 才可续租、active/returning 提供退租及进度、completed/ended 不恢复已关闭的操作；身份与入仓入口根据 identity_status 分流。押金和发票仍保留历史可查询性。
5. m01-rebaseline-01.js：修正多订单主任务排序。即将到期、退租中、押金待处理有明确主操作；已结束及押金完成后不继续冒充当前在租。服务区按状态显示续租/退租相关入口；个人信息子页明确使用 profile 入口。
