## 四档仓型素材门禁

- 本候选 S02 `r3UnitImage` 按容量：≤1.5m³ `mini`，≤5 `small`，≤15 `medium`，>15 `large`。
- 每类有不同内容哈希的 `336×312.webp` 门店仓位缩略图和 `640×480.webp` 容量参考图片各一张；四类图片都存在于候选 GitHub tree。
- **3.5m³ 与 5m³ 图片完全一致**，这在“仓型档位示意”语义下符合四档映射；但两者具体长宽高 `1.4×1×2.5m` 与 `2×1×2.5m` 不同，**不可把同一图称为精确实际仓位照片**。
- 旧 UNIT-IMAGE-REBUILD 规则：迷你仓无新增隔板、小图需能辨识箱包；3m³ 以上视觉仓高2.5m；10m³以上应表现独立房间天花、较大仓对开门、绿或青绿平开门、不用卷帘或推拉门。当前 `S02` 缩略图已通过图片加载和不同档位映射检查，但**图片真实性、内部结构以及在88px下的物品比例尚需人工逐像素核验**。
- 以本 Gate05 CI 的四档 `S02-FOUR-TIER-375/390/980.png` 与 `gate.json` 作为素材人工复核的同一 HEAD 证据；无法从单一示意图判断具体容积，文字保留明确数字。
