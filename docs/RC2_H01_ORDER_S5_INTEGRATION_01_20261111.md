## 二、业务规则冻结

- 待支付订单有效期：从成功创建开始 **3 小时**；报价保持 5 分钟。以原订单 `createdAt / expiresAt` 为准，刷新和切前后台不重置。
- 未支付期间预留仓位；取消支付弹层本身不终止订单。
- **支付失败即原订单失败，立即释放预留仓位和权益锁**。旧单不可再次付款；重试须选仓并建立新订单。
- 三小时到期 / 原价库存失效：终止旧订单，释放库存，不允许原订单继续付款。
- H01 继续支付直接进入 O01，对应订单 ID 进入前验证；O03 可按原订单 ID 恢复有效预留，不重置剩余期限。
- 过期、失败或价格变动时，统一引导新选仓及新订单；订单历史保留。
- 以上均为当前浏览器模拟业务引擎规则，**不等同于真实支付和后端锁仓已接通**。
