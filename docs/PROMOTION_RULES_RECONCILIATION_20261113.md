# 促销与优惠权益规则核对｜2026-11-13
## 当前策划范围
1. 特价仓：特定门店的特定仓位特价。
2. 租期折扣：通常租期越长折扣越大。
3. 送搬运：已知当前活动讨论包含租期至少6个月；其他距离门槛、基础服务范围、次数需依据最新活动配置核定。
4. 送租期：特定仓位/门店固定活动，亦可能由销售主动议定。
5. 优惠券：独立优惠权益，不与特价仓/租期折扣混为同一价格字段。
6. 销售人工赠期/议价：须区分固定活动与个案授权。
