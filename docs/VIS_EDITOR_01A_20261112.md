## 运行
在工具分支的 app 目录运行 Windows PowerShell：

    python -m http.server 4173

打开：http://127.0.0.1:4173/tools/vis-editor-s01.html

不建议直接双击 HTML，因为 file:// 同源访问限制会影响 iframe 编辑功能。

## 主要操作
1. 左侧选择目标区块，或点击预览中的元素。右侧编辑尺寸、间距、字体、圆角与价格色值；不允许直接改文案与业务数据。
2. 视口为 375×812 或 390×844；页面状态包括普通浏览、已选需求、未定位、无匹配、扩展推荐、远距离。
3. 支持选择模式、体验交互、撤销重做；方案 A/B 相互独立。
4. 点击「保存方案」写入当前浏览器 localStorage。导出 JSON 和 CSS 供评审与后续人工接线。更换浏览器或清缓存可能丢失本地保存，请导出归档。
5. 列表由业务脚本重新渲染后，编辑器会重新应用视觉覆盖，原始业务算法保持不变。

## 限制
- 原型使用多层 CSS @layer 和 !important；导出 CSS 只是候选补丁，不可直接当作优先级正确、可合并的生产 CSS。
- 同类卡片的变更是批量视觉覆盖；本版不支持单张卡的任意业务差异化。
- CSS 预览是在独立 iframe 里使用内联 important 实现，未修改原型源文件。
- 仍需 375/390 浏览器回归、多状态交互、A/B 保存恢复、代码层叠与截图人工验收；不能把静态文件存在等同于运行 PASS。
- 禁止自动合并 main、发布 Netlify 或创建 release。
