## A/B 设计对比

| | A：高效商业决策 | B：亲和生活服务 |
|---|---|---|
| 目标 | 距离、匹配仓位、整期价和行动入口最显眼 | 商业决策结构不变，更多生活感与门店实景 |
| 首页 | 紧凑走廊 hero、两项任务、横滑推荐卡 | 加大门店视觉、温暖留白和任务板块 |
| S01 | 高信息效率：88×88图片、匹配结果、整期价和双操作 | 较大图片、柔和卡片与更多舒适间距 |
| S5 | 需求、整期租金、推荐优先级靠前 | 大图和品牌亲和力更强，同时保留整期租金 |
| 风险 | 若排版过密则缺少品质感 | 若照片和留白过度则压低首屏决策效率 |
| 建议 | 优先作为效率基线候选 | 可抽取摄影比例、留白和色彩补强 |

两种方向都遵循用户 **A 商业成熟度 > C 亲和易用 > B 品牌品质** 的优先级，不做纯装饰性 UI。
