## 4. 人工视觉审阅结论与剩余问题

**已改善：** 取消列表浅灰绿通底；正常门店不再层层套边框卡片；深橙价与品牌绿按钮职责区分；真实门店照片与价格、完整地址并存；浏览态与带需求态的价格强调风格一致。

**仍未达成熟商用界面质量：**

1. **P1：** 容量旁原有仓号、面积及“适合物品”仍在一行争夺空间；直接放大字体可能导致第2按钮进入滚动区。下一步应在不删文案前提下做信息分组与行内换行方案探索。
2. **P1：** 顶部城市搜索、三筛选、快捷筛选、需求栏都合法，但纵向节奏仍偏碎；需以真实使用路径优化整体密度，不应删模块。
3. **P1：** 主价橙是否优于深墨需要用户最终视觉裁定，不能擅自推广至 H01、S5、O01。
4. **P1：** 部分标签、仓号与小单位仍采用11–12px；125%字号放大、超长地址及极值金额未在本轮全面验证。
5. **P2：** 外层底栏图标/颜色仍来自共用壳；本轮没有跨页替换图标或改变路由。
