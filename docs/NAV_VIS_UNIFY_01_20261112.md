## 初步方案裁定与严控改动

**推荐的候选方向（仅提议，未获用户终签）**：

1. 以现有**H01批准母版的外观**为整体图标造型参考，四标签、第三位日历与路由均不变；为S01/M01新做/校准四枚匹配母版视觉的透明独立资源（含默认和选中态）。
2. H01原 `nav_original_375/390.png` 冻结不动；新增可替换图标只能在**独立隔离候选**试装，通过375/390人工同屏、像素/对齐及点击测试后，再评估是否用在S01/M01。不能通过直接裁剪模糊贴图来冒充独立高质量图标。
3. 不直接把H01贴图换成VIS07，也不采用历史NAV-ICON-01B整套四图标：前者导致用户批准首页视觉漂移，后者违反预约订单的业务/语义契约。
4. 一切图标试装前保留 `current / candidate` 并排截图，不修改布局区、底栏高度、安全区、文本标签、触控目标或导航状态机。整站统一仍须用户审核。
