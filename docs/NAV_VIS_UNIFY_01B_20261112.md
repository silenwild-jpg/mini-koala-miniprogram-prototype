## 本轮设计资产

仅提供**8个独立可编辑SVG文件**于 `app/assets/nav/current-four-01b/svg/`，24×24 viewBox，无外链。
提供两态：

| 当前入口 | 源文件 | 造型与区分 |
|---|---|---|
| 首页 | `home-active.svg` / `home-inactive.svg` | 沿用H01实心绿色屋顶/房屋的视觉方向，未选描边 |
| 附近门店 | `stores-active.svg` / `stores-inactive.svg` | 圆角定位牌+图钉；不同于旧B的“找仓放大镜” |
| 预约订单 | `calendar-active.svg` / `calendar-inactive.svg` | 双扣日历，两态一致；不擅换成旧B“找仓” |
| 我的 | `mine-active.svg` / `mine-inactive.svg` | 头像轮廓与实心激活态 |

候选主色 `#087253`、未激活灰蓝 `#8B9FAB`，补色 `#DCECE5`，图标自身透明背景。
真正试装时必须遵守当前按钮≥44×44、文字标签和导航高/安全区/交互均不变；
图标本身建议26px，不能让图标变小成不可辨认的细线。
