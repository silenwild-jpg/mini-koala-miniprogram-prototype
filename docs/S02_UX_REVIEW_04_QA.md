## 数据来源边界
三档存取时间是业务方授权的补齐值，并非现场营业时段证据；门店实际数据更新后必须覆盖同 ID 的当前值。
公交地铁时间采用可稳定复算的预设估算，不能被当作即时交通路况；实际地图插件接入后必须替换。
地图容器现在是前端矢量底图，不含已验证道路坐标或真实路径。
