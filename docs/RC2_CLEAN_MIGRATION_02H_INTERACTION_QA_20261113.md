## 2. 已确认的实现与证据

### S02 交通路线
- `demo/app.js` 维护 `可选仓位/服务设施/交通路线` 三种 tab 状态。
- `s02Route()` 提供地图区域、门店地址、四种出行方式和「导航到门店」按钮。
- `s02TravelMode()` 更新当前出行方式；`s02OpenMap()` 根据演示坐标或地址生成高德导航/搜索 URL。
- 当前地图区域为原型 SVG 地图占位，非真实路线规划 API。该范围符合原型演示阶段，不作为线上地图服务通过证据。
- 本轮新增浏览器测试验证 tab/面板/方式切换/URL 构造；不验证真实手机高德 App 是否被系统接管。

### S5 价格与推荐卡边界
- 现有 `verify_s5_final_vis_signoff_04c_states_browser.cjs` 覆盖双门店、单门店、无匹配、近容量、组合仓、展开、大容量无匹配、短租等8类状态，并检查 375/390 横向溢出、价格是否裁切、整期价计算、月均价与管理费50、CTA触达尺寸、服务标签数量及考拉E存位置。
- 已有断言：`priceFits`、整期租金=`月均价×租期`、管理费=50、卡片不超屏宽、购买按钮最小触达尺寸、服务标签不超过2。
- 仍缺少专门的极长门店名称/超长促销标签/人为极大金额的独立 fixture；不以普通样本覆盖推断极值已通过。

### M01 生命周期
- `verify_rc2_final_vis_signoff_04_browser.cjs` 覆盖续租报价、确认后待支付不提前延长租期、取消、失败/恢复、支付成功增加租期、发票支付记录和身份流程约束。
- `verify_m01_ia_03_browser.cjs` 覆盖 375/390 资产列表和历史需求入口。
- 现有截图可见两笔在租资产与结束历史；仍需人工检查真实页面长内容层级，但不要求真实业务数据。

### O01 费用/协议/支付
- `verify_rc2_merge_ready_04_browser.cjs` 已验证容量/租期继承、费用计算、管理费50、协议未确认阻断、待支付记录与支付流程面板。
- 375/390 截图包括订单确认上/下屏、协议阻断和支付面板。
- 需保留演示语境：不测试真实支付渠道；费用数据按演示常量检查。协议正文与法务内容不是本原型视觉门禁。
