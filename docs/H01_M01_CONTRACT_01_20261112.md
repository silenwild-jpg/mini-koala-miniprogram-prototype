## 共享规则

1. H01 和 M01 从 H01_STATE_POLICY.derive(state,core) 得到同一份按分数排序的业务待办队列。H01 仍显示一个当前主任务；M01 显示同一主任务及账户记录。新增不可枚举 tasks 供 M01 使用，保持 H01 既有投影和快照语义不变。M01 旧独立选项逻辑仅留作独立旧测试的兼容回退，后续应清理。
2. 待支付订单时效为 3 小时（原订单 createdAt + 10,800,000 毫秒），报价有效期为 5 分钟。M01 同步展示原订单剩余 HH:MM:SS。关闭支付页、浏览新城市不会重置截止时间；M01「继续支付」调用核心 resumePendingOrder，恢复同一 ID 的城市、仓位、起租日期和需求，不创建新的订单。
3. 支付失败和超时均需新建订单，原单保持历史记录；失败释放旧预留仓位和权益锁，不能原单重试。M01 使用 H01 现有「重新选择仓位」流程。
4. 身份验证、入仓资格、退租、验仓和退款基于同一中央生命周期。不显示假门禁口令或开锁成功，仓门设备功能仍是演示入口。自然到期租约仍可办理退租和押金，不能误用旧 M01 active-only 规则。
5. M01 CSS 仅在个人中心和旧服务子页生效；H01 原营销母版文件零改动；未引入任何对比功能。
