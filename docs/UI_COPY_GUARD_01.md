# UI-COPY-GUARD-01｜全站界面文案减噪规则

状态：用户确认，2026-11-03；适用于 H01 / 容量估算 / S01 / S02 / S5 / O01 / 订单与生命周期页面及一切弹层。

## 核心原则
界面只承载行动所必需的信息。禁止新增重复解释性描述、教学式文案、无决策价值的运营性说明、技术性状态解释和装饰性段落。不得为了填补空间添加文案，不得将已有同一含义拆散成多个提示。

## 应保留
- 选仓容量、适用物品、可信价格、库存、存取时间和必要服务差异。
- 必要的容量不足、组合仓分仓存放、价格条件、支付、退款、手机号授权及隐私/协议提醒。
- 错误提示与恢复动作；无法可靠获取路线时以简洁方式提示演示或未知，不将模拟距离当作实时路线。
- 法律和平台要求的必要说明（不得以减噪为由删除）。

## 表达检查
1. 一个信息仅出现一次，首选在最相关的操作位置展示。
2. 优先短标签、数据及明确动作；默认不配说明段落。
3. 不新增为了表达同一信息的二级卡片、图标矩阵、重复辅助入口。
4. 文字优先解决用户决策或安全问题，不能只解释界面本身。
5. 特定页面已经确认的状态、示意图、价格语义和可用性不得因删文案被误导。
6. 上线前验证文案的真实数据来源；演示素材只用于内部候选。

## 当前 S02 实施边界
- 门店头图左下角采用门店数据源的“存取时间：24小时”或“存取时间：HH:MM-HH:MM”；没有可信字段时隐藏，禁止默认写死“24小时”。
- “门店服务 / 交通路线”切换无额外介绍段落。
- 交通路线：大幅地图插槽、地址、出行方式、路线摘要与导航操作。坐标和路径未核验时呈现标记为演示的示意地图，不编造街道级实时导航。
- 普通浏览估算入口保留短文案，已携带需求时不重复出现。

## 验收
新增 UI 文案须说明：用户此刻需要它完成什么决定或规避什么风险？若无明确答案，默认移除。375/390 两尺寸及主态/交互态/异常态均检查文案换行与注意力负担。
