## VIS-GUARD 校验清单

1. **母版优先**：同视口（375×812/390×844）、同城市、同登录与数据状态，对比原图→运行图。不可只凭历史视觉截图或单个PASS说明“终签”。
2. **结构冻结**：禁止未经批准改变页骨架、左右边距、图文关系、按钮主次、屏高与信息块顺序。
3. **避免 AI 同质化**：不可为“统一组件”额外创建大面积边框/阴影/背景色/嵌套卡片；旧原型样式禁止回流。
4. **局部合法覆盖**：11/03 S01三筛选属批准的新局部改变；不授权重新设计门店卡、价格、整个S01页面。
5. **批准与测试分离**：视觉原图缺失、压缩失真或容器尺寸不一致时标 HOLD，不能凭当前仓库 PNG 自动补选新母版。
6. **探索可以独立进行**：UX-ZEROBASE意见先记录为建议；对既有冻结结构进行变更须新版本批准，保留反向追溯。
