## 信息/规则交叉检查
1. **状态判定来源必须同一套 H01_STATE_POLICY**：当前 M01 消费共享任务队列；严禁因视觉移植替换 `h01-state-policy-01.js` 或 `m01-rebaseline-01.js`，否则多订单优先级、3小时付款倒计时、已付未验证、待起租禁开锁等可能回退。
2. **H01 与 M01 不宜完全重复**：H01 是最高优先任务与快速操作；M01 是多仓资产与订单明细，当前 M01 已在普通在租态抑制多余任务卡。H01 的“我的订单”是明确多订单的管理入口，不是自动判定为冗余。
3. **不新增首页第三个营销任务卡**：此前“立即下单”作为双任务卡区域的独立视觉探索，尚未最终获批，继续通过底栏“预约订单”中的快捷下单可达；该议题不与 A+C 任务态混合。
4. **目前字体/底栏问题**：PR #123 既有中文 CJK 40/40 测试 PASS，任务 CTA 最小48px，正常在租帮助至底栏距离据该 SHA 为 375px约37.6px、390px约55.2px。移植到 RC2 后必须重新跑同一 SHA，不直接沿用旧几何数值。
5. **图片构图风险 P2**：仓库原图约1152×720、候选活跃态图高96px/104px，中心裁切估算损失53%～55%垂直信息。不是业务逻辑缺陷；不得为此新增高卡或遮挡订单入口。
6. **底部导航跨页一致性**：截图可见 H01 与 M01 的图标表现有差异，归类为 P2 视觉对齐检查，不能仅凭图片推断导航功能已失效。
7. **价格**：H01/S01 公开月租起价已在 RC2 `f6de38bc` 调整；独立 PR #123 的 `home-bridge.js`、`fixtures.js` 等过时业务文件禁止覆盖。
