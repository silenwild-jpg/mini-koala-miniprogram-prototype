## 2. S01 页面框架（结构冻结）

从上到下：

1. 标题「附近门店」；城市选择 + 搜索门店、区域或地址。**不额外加入顶部返回箭头**；保留底部「首页 / 附近门店 / 预约订单 / 我的」主导航。
2. 主筛选栏仅 **「排序 / 距离 / 服务」** 三等分；「价格优先」仅是排序菜单内选项，禁止第四个价格筛选或“只看单仓”。
3. 「特价仓 / 送搬运」为二级轻量快捷筛选，可见芯片约28–30px；实际可点击区域≥44px。选中时弱绿色反馈。
4. 需求辅助栏放在两个筛选层**之后、门店列表之前**。浏览态提供容量估算入口；匹配态展示完整「容量 · 租期」并保留一个修改入口。文案的精细口吻**暂不做最终字句冻结**，不得拆分为两个独立修改入口。
5. 门店列表固定平面化，无重复“查看门店”文字按钮，不使用大块绿色营销卡、额外嵌套卡或大量阴影；无结果进入顾问与考拉E存双兜底。
6. 底部导航与滚动、搜索输入、下拉层定位不互相遮挡；既有三筛选为吸顶。

## 3. 卡片三态与位置契约

| 条件 | 第1、2家实体门店 | 第3个列表位 | 第4家及以后 | 价态/动作 |
| --- | --- | --- | --- | --- |
| **浏览态**：未同时确认容量及租期 | 与其他实体门店**完全同源的紧凑卡** | **考拉E存独立服务卡** | 统一紧凑卡 | 门店公开最低 ¥/m³/月，不展现具体仓号/仓位，不直接显示「立即下单」 |
| **匹配态**：有效容量 + 用户确认的1–60个月租期 | 每家展开**一个**最匹配的可售仓位 | **考拉E存独立服务卡** | 紧凑门店入口（不展开仓位） | 主展示仓位整期租金、副展示「¥X/月 × N个月」和租期折扣；仓位CTA「立即下单」 |
| **无结果**：筛选无门店，或完整需求下无可用匹配仓位 | 不伪造第一、第二家匹配卡 | 考拉E存可作为备选，不强求列表固定位 | 无正常卡 | 第一主动作「顾问帮我找仓」，同时保留「清除筛选」；不将“需求没填完”误判无库存 |

**推荐位裁定**：第1家优先可售库存满足需求条件的最近门店；第2家优先附近合理范围内低价且可售的门店；第3位固定考拉E存服务。受搜索、距离、服务、排序等用户显式筛选影响时按当前条件重排；并非强行展示不符合条件的门店。未定位时可用稳定演示公里数辅助推荐，但不可声称真实定位。

位置定义是**S01自己的**，不能把 H01 首页第3张灵活运营推荐卡错误改为固定考拉E存。首页第3张仍为灵活运营位。

> 实现提醒：S01 当前 `s01-r2-bind.js` 的第三位通过列表索引插入独立考拉E存，前两家匹配态通过 `state.matched` 走 `expanded-one`。用户编辑中的单字段草稿不得被当作完整匹配态。推荐排序允许合适库存、距离和演示区域规则共同决策；不能为了强制“最近”而把不可下单仓位放在第一位。

## 4. 字段优先级（已冻结，不等于像素冻结）

### 4.1 浏览态｜所有实体门店统一紧凑卡

| 顺序 | 字段 | 条件 / 规则 |
| --- | --- | --- |
| 1 | 门店真实或已接入的展示照片、门店名称 | 列表照片现行基线88×88，文本溢出省略；照片实体映射作为演示素材，不声称已取得正式门店真实性验证。 |
| 2 | 促销 / 服务标签 | 信息优先级「运营/促销 → 主要服务特征 → 其他服务」，紧凑卡当前可见**最多2个**，匹配态展开卡**最多3个**；最终数量须服从版面验收，不盲目加满。 |
| 3 | 地址 / 距离 | 详细地址列表单行 CSS 省略号；距离独立不压缩，详情可见完整地址；距离可用稳定**演示公里数**，不得借此标成真实授权定位。 |
| 4 | 门店公开最低单价 | `门店低至 ¥X/m³/月`（参考期口径源自 `presentation.cubicReference()`）；浏览与匿名排序无需手机号验证。 |
| 5 | 整卡点击提示 | 整张卡可进入 S02，右侧弱箭头；无冗余「查看门店」文字按钮，保持键盘可达和触达反馈。 |

### 4.2 匹配态｜前两张展开门店卡

- 门店头部仍含 88×88 照片、名称、标签、地址、公里数；详情入口与仓位下单点击区域互不误触。
- 仓位**第一行**：弱化轻标签 `仓号 A003`（格式 `A001–D030`、单店不重复、按内部仓位ID稳定映射）＋ **19–20px强化容量** `3.5m³`＋弱化适用场景。仓号是演示字段，不是可证明的真实物理库存编号。
- 仓位**第二层**：整期租金主价20–21px左右，旁边11px左右浅绿「6.5折」等当前租期系数标签；下行 `¥260/月 × 12个月`；右侧独立48px「立即下单」。两层**属于同一个平面列表区**，不加阴影背景小卡。
- **不要再并列展示门店最低立方米价**；不显示「整期租金」「月均约」等重复主文案，不默认展示缺乏比较基准的划线原价。
- 这里的主价是**仓位租金**，不等于 O01「首次应付」，后者另计押金、一次管理费和适用券。优惠标签只反映当前演示费率的租期折扣，不得不经裁定叠加认作“券后折扣”。
- 需求容量和实际仓位容量可能不同，分别写「需求 3m³」与「仓号 A003 · 3.5m³」，不加冗长解释。
- 正式提交前必须同时有有效容量、已确认的1–60月租期；**不预设12个月**。主页/列表「公开最低单价」使用的12个月内部参考期不是已选租期。

### 4.3 交互与回流

| 入口 | 既定动作 |
| --- | --- |
| 浏览态整卡 | 进入该店 S02 |
| 匹配态门店头部及详情箭头 | 进入该店 S02 |
| 匹配仓位「立即下单」 | 选择当前具体仓位 → O01 手机号验证/订单确认既有链路 |
| 需求「立即估算 / 修改需求」 | 进入容量及租期一体编辑，不拆成独立的容量、月份弹窗 |
| 「清除筛选」 | 恢复搜索、排序、距离、服务和快捷筛选；**不清城市及已确认需求** |
| 无匹配「顾问帮我找仓」 | 顾问线索路径；考拉E存保留独立出口 |
| 「查看更多」和列表返回 | 保留筛选/滚动回流，不恢复独立U01仓位详情或任何对比模块 |

## 8. 修改门禁与下一阶段交付

1. **结构冻结后**，常规视觉优化无需改变 `unit.id`、推荐顺序、容量+租期完整性、价格计算、跨页返回、库存及订单身份。
2. 任何重新引入「查看门店」文本按钮、价格顶栏第4筛选、对比功能、U01、首页第三张固定E存、未选需求时具体仓位，**默认不准入**。
3. 允许有可复核用户任务证据的 P0/P1 推翻旧决定，但必须记录：来源、所破坏的冻结条款、业务收益、375/390截图、跨页影响、需要批准人和回滚方案。
4. 进入 `VIS-SYSTEM-01` 全站视觉规范：基于 H01 母版与 S01 本结构基线，为 H01/S01/S02/S5 建立统一 **typography / spacing / tags / price / interaction** 系统；只在结构不变的前提下逐区终签。
5. 之后独立执行 `S01-VIS-FINAL-10`，补齐整页长列表与多状态人工签收，方能解除**视觉** HOLD。正式归并另需确认分支与业务合并门禁。
