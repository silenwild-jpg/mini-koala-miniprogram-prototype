## 素材事实
- `store-curated/v1/mapping_manifest.json` 明确写着 `identity_verified=false`，所有 SIM_* 图片是用户提供的品牌仓储环境在**演示槽位**上的配置，**不是逐家实体门店身份的实拍验证**；原型阶段无需要求验证真实门店数据，但产品显示应避免引起“这是我租的具体仓”的误解。
- BJ01 `hero.webp`（1152×720）与 `card.webp`（512×512）均来自 `IMG_20250317_143728_1.jpg`，family=`white_signed_A001`。前者带可见 A001、400 电话牌、消防设备，后者也带 A001。不存在独立的同槽位无编号备用照片。
- PR #142 的 `object-position:50% 74%` 已在 375/390 受测图中避开 A001，但右侧电话牌与左侧消防设备更突出，门店空间信息价值有限。
- 另有 BJ03、SH01、SH02 等其它环境照片，但每份标有不同仓号/门店信息（例如 B021、A040、B035），不可直接替换成 BJ01 的“实景”。现成首页品牌图、静安门店外景亦不能冒充 BJ01。
- 两次生成的设计示意排版含虚构 PR、SHA 与“已验收”文字，**已明确排除，不作为源素材或验收证据**。

## A / B 对照设计

| 状态 | A＝PR #142 照片焦点调整 | B＝本分支无图在租备选 |
|---|---|---|
| 待支付 | A 阶段进度 | 完全不变 |
| 待入仓 | C 到店照片、时段、导航/起租门禁 | 完全不变 |
| 正常在租 | C 在租紧凑环境照片（96/104px），续租/服务与订单在下 | **去除在租环境照片**；保留开锁、导航、续租/服务、订单、使用须知；不留空容器 |
