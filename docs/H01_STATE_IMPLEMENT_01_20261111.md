## 业务边界

- “共享状态”指**现有 RC2 浏览器演示内会话状态**，不等于真实 CRM、微信支付、门禁或在线租赁系统。
- 继续支付先进入订单页检查有效性；取消、过期、失败、失效只进入「查看订单」，不允许旧单自动重试。
- 已支付不等于已获得入仓权限；展示依赖实际 `identity_status`、`lease_status`、起租日。
- 续租申请/报价使用既有订单生命周期；当前首页未创建新的确认或支付 API。
- 加租意图记录在单独会话键中供后续流程消费；当前 QUICK/S01 不保证自动预选当前门店。换仓顾问线索尚未证明已发送真实 CRM。
- 原有后台服务、库存、退款/应急真实性均未在本任务中获得任何新的业务确认。
