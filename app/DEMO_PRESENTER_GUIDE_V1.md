# Demo Presenter Guide V1

## 5 分钟管理层演示

### 0:00–0:30｜产品是什么

在 Demo Hub 解释：用户从“不知道需要多大”开始，小程序依次解决空间判断、附近门店、真实仓位、完整价格、成交和租后管理。

### 0:30–3:30｜Story 01 第一次租仓

点击「开始 5 分钟核心演示」，按底部「下一步」顺序讲：

1. 新用户不需要先懂仓型。
2. 完成估算得到约4.8m³ / 6个月，并获得新客券。
3. 需求带回附近门店，只比较真正匹配的供给。
4. 门店里展示真实可租仓位和已售出容量。
5. U01 同时说明库存紧迫感、整期价格和自动优惠。
6. 确认订单保持同一 Quote。
7. 支付后进入待使用，不中断生命周期。

### 3:30–4:20｜库存与转化

从 Hub 进入 Story 03：强调稀缺信息不是随机促销文案，而是匹配库存 → 同容量剩余 → 已售出 → 已售罄的连续供给信号。

### 4:20–5:00｜租后能力

进入 Story 05，快速展示待使用、用仓中、续租、退租和押金，说明产品不是只解决一次获客成交。

## 市场 / 销售演示

优先：Story 03 + Story 04。

重点说明：

- 广告流量可以先估算，也可以先找门店。
- 库存紧迫感承担真实供给稀缺提示。
- Coupon 是转化激励层，不改变基础租期折扣规则。
- 6个月 canonical：¥3,440 → -¥200 → ¥3,240 → 一次支付 ¥3,863。
- 后续可把未成交召回券、渠道券接入 CRM / Remarketing。

## 运营 / 门店 / 客服演示

优先：Story 05 + Story 06。

重点说明：

- 已售出容量和整店已售罄的恢复路径不同。
- 支付失败与库存变化均有恢复路径。
- 待使用 / 用仓中 / 即将到期的主任务不同。
- 续租、退租、押金、发票、历史订单已纳入统一生命周期。
