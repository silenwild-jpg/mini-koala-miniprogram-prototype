# Visual Elevation V2.1 — Density Harmonization PATCH

## Scope
仅处理页面密度专项 Review 中的五个优先页面：Estimator、U01、RN01、IV01、B2B。保持业务文案、模块顺序、价格/折扣、状态、字段、CTA 含义、页面路径和交互逻辑不变。

## Changes

### Estimator
- 个人/家庭与商家/企业场景从“8 张等权白卡”收敛为纸面型轻选项。
- 未选项无白底卡面，仅选中项成为强 Surface。
- 375px 下 8 个场景中白色 Surface 从 7 个降为 1 个。

### U01
- 仓位身份卡与空间 Hero 合并为半透明浮层，降低“图片 → 白卡 → 价格卡”的三段堆叠感。
- 租期选择进一步弱化未选按钮。
- 价格成为全页唯一强 Surface，使用深绿底 + 铜橙主金额；押金/管理费保持同一决策区内的事实行。

### RN01
- 去除外围续租大白卡。
- 续租月份改为轻量选择项，仅选中项深绿强调。
- 自定义租期、说明与续租状态改为留白 + 分隔线结构。

### IV01
- 付款记录改为平面信息行。
- 发票表单取消外围大白卡，输入控件本身承担边界。
- 已提交申请改为分隔线信息区。

### B2B
- 形成“空间与租期 / 存储与搬运 / 联系信息”三段编辑节奏，主要通过留白与分隔线表达。
- 大量未选 Chip 从白卡改为暖灰轻选项；只有选中项深绿强调。
- 租期折扣从悬浮角标收回选项内部，减少噪点与溢出。

## Density Rules reinforced
1. 一屏只保留一个强视觉 Surface。
2. 表单输入框有自身边界时，不再套大白卡。
3. 多选项场景只有选中态使用高对比 Surface。
4. 价格/状态/事实优先使用信息行而非独立卡片。
5. 连续白卡必须通过无卡片分组或分隔线打断。

## Business freeze
五个目标 HTML 的 `<body>` SHA-256 均与 V2 Refinement 输入版本一致；本轮仅新增 head stylesheet link 与外部视觉 CSS。
