# Sprint 1C — 租期与推荐 High-Fidelity Visual Closure V1

## 1. 范围

本轮基于 **Mini Koala Prototype Baseline 1.0** 与 **Mini Koala Visual Design System V1**，仅对 Estimator 内的 **S5「租期与推荐」**进行高保真视觉收口。

执行性质：**VISUAL PATCH / CSS only**。

明确不修改：
- 页面 `<body>` 结构
- 中文文案
- 租期与折扣计算
- 门店推荐算法
- 推荐门店顺序
- 库存匹配
- NOMATCH 业务逻辑
- 考拉E存业务逻辑
- 地址快捷修改交互
- CTA 与页面跳转

## 2. 视觉目标

1. 将**整期总租金**建立为推荐卡的唯一价格主视觉。
2. 将月租、折扣、当前租期下沉为解释层。
3. 门店事实按“推荐角色 → 行政区/门店 → 地址 → 剩余仓/匹配仓位 → 距离 → 价格”建立稳定层级。
4. 用仓地址做成可识别的轻量修改入口，不抢推荐卡视觉。
5. 考拉E存采用与实体仓一致的组件语法，但保持次一级权重。
6. NOMATCH 使用可恢复视觉，而不是错误态。
7. 375×812 / 390×844 下无横向溢出、标签内部折行或浮窗遮挡核心价格。

## 3. 主要视觉调整

### 当前估算
- 由大面积浅绿块收敛为白色决策卡。
- 当前估算范围使用深绿标题层级。
- 容量步进器按 4px Grid 重做尺寸与间距。

### 租期选择
- 统一 48px 轻量租期卡。
- 折扣角标降级为小号暖橙提示。
- 选中态使用浅绿，而非重色填充。
- “其他租期”改成标准 Utility Surface。

### 搬运提示
- 保留原文案与规则，仅降低视觉权重。
- 使用浅绿色信息卡，而不是第二个主卡片。

### 用仓位置
- 全宽白色轻量入口。
- 地址单行省略，右侧保持“修改 ›”。
- 原有 prompt 快捷修改交互完全保留。

### 实体门店推荐卡
- 卡片恢复完整纵向信息结构，避免右侧窄价栏压缩。
- 推荐角色使用轻量胶囊。
- 行政区作为事实标签，门店名为主标题。
- 地址单行省略。
- `剩余仓 X个 · 匹配仓位 X个` 为次级绿色事实信息。
- 距离进一步降级。
- 价格区单独分隔：
  - **整期总租金：28–30px 暖橙主视觉**
  - 月租：12px 次级信息
  - 折扣：弱绿色说明
  - “整期预计省”使用浅橙小胶囊

### 考拉E存
- 去除较强渐变和大面积强调。
- 使用浅绿 Standard Alternative Card。
- 标签保持单行、横向可滚动。
- 套餐总租金仍为价格主视觉，但整体权重低于实体门店推荐。

### NOMATCH
- 浅暖色恢复卡，不使用红色错误态。
- “调整空间需求”为恢复主行动，“客服协助”为次行动。
- 下方相近实体仓位卡弱化，避免误认为正常匹配结果。

## 4. Visual Freeze

Sprint 1C 通过后，S5 页面应继续遵循：
- 一个主价格
- 标签不内部换行
- 地址单行省略
- NOMATCH 不使用错误态视觉
- 考拉E存不超过实体推荐视觉权重
- 不因视觉理由改变推荐逻辑或价格逻辑
