# Sprint 1D — S01 附近门店 High-Fidelity Visual Closure V1

## 1. 范围

本轮基于 **Mini Koala Prototype Baseline 1.0**、Sprint 1A–1C 与 **Mini Koala Visual Design System V1**，仅对 **S01「附近门店」**做高保真视觉收口。

执行性质：**VISUAL PATCH / CSS only**。

明确不修改：
- 页面 `<body>` 结构与中文文案
- 普通浏览 / 已关联需求 / NOMATCH / 扩大范围 / 远距离挽回状态
- 价格排序、距离筛选与其他筛选逻辑
- 门店排序、需求匹配和推荐算法
- 首页/推荐页传入 S01 的参数
- 考拉E存默认第 3 位与 >5km 无门店兜底首位规则
- 门店详情跳转、localStorage 状态与全局客服逻辑

## 2. 视觉目标

1. 将“用仓位置 + 搜索”收敛为一个完整找仓 Surface。
2. 让距离/价格/筛选成为 Utility Chips，不抢门店内容。
3. 普通浏览门店卡突出门店名、距离、剩余仓与发现价，减少旧版工具感。
4. 已关联需求门店卡与 Sprint 1C「租期与推荐」建立同一视觉语言：门店事实在上，整期价格独立在下。
5. 考拉E存保留服务差异，但视觉权重低于实体门店。
6. NOMATCH 继续强调“可恢复”，不使用错误态红色。
7. 375×812 / 390×844 均无横向溢出、核心价格遮挡和标签内部换行。

## 3. 主要视觉调整

### 找仓区域
- 用仓位置、切换入口、到店方式与搜索合并到一个 16px 圆角白色 Surface。
- 定位图标统一为线性绿色视觉，不再让 Emoji 成为主识别元素。
- 搜索作为该 Surface 的第二行，使用弱灰辅助层级。

### 需求 / 估算提示
- 普通浏览「不确定用多大仓？」使用浅绿信息条。
- 已关联需求使用同一信息条语法，`修改需求` 保持 Text/Outline 次级行动。
- NOMATCH 顶部提示使用暖中性色，而不是错误红。

### 筛选工具
- 距离、价格排序、筛选统一为 34px 胶囊 Chip。
- 选中状态只使用浅绿底 + 深绿字。
- 工具层与门店卡之间保持明显视觉权重差。

### 普通浏览门店卡
- 16px 圆角 Standard Card，白底 + 浅描边 + 极轻阴影。
- 门店图、门店名、类型标签、行政区/所属小区、路线建立稳定层级。
- 剩余仓位和单位发现价改为同一底部事实行。
- 价格使用冻结的暖橙 `#D56A1C`，后缀明显弱化。

### 已关联需求门店卡
- 改为纵向结构，避免旧版右侧窄价栏压缩门店事实。
- 推荐角色使用浅绿胶囊。
- 行政区 → 门店名 → 地址 → 剩余仓/匹配仓位 → 距离为稳定事实层。
- 底部独立价格区：
  - **整期总租金 26–28px 暖橙主视觉**
  - 月租 / 折扣为次级说明
  - 整期预计省使用浅橙小标签
- 与 Sprint 1C 的推荐卡保持同一种价格阅读顺序。

### 考拉E存
- 使用浅绿 Secondary Service Card，不再用较强渐变和重描边。
- `不限门店` 与三个特性标签保持单行。
- 普通浏览仍位于实体门店第 3 位；>5km 无物理门店时仍按既有规则进入兜底位置。

### NOMATCH
- 恢复卡采用浅绿恢复 Surface。
- “调整需求”为 Primary，“客服协助”为 Secondary。
- 考拉E存与容量相近实体门店继续作为恢复方案，不伪装成正常匹配。

### Bottom Sheet / 租期工具
- 统一到 Sprint 0 的白色 Sheet、12px 圆角输入、浅绿选中态。
- 租期折扣角标继续使用暖橙辅助色，不提升为主视觉。

## 4. Visual Freeze

Sprint 1D 通过后，S01 应继续遵循：
- 位置与搜索保持一个 Surface
- 筛选工具不高于门店内容权重
- 普通浏览只显示发现价，不制造需求匹配语义
- 已关联需求整期总价为唯一主价格
- EStore 标签内部不换行
- NOMATCH 使用恢复视觉
- 不因视觉原因改变排序、匹配、EStore 位置和跳转逻辑
