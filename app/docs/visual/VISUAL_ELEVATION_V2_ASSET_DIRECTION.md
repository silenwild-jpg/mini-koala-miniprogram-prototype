# Mini Koala Visual Elevation V2 — Asset Direction

**阶段：** Asset Direction + Controlled Rollout  
**基线：** Hi-Fi Visual Baseline 1.0 FINAL + Premium Pilot  
**目标：** 用真实、统一、克制的空间资产替代“示意图驱动的高级感”，让品牌从 UI 高级感升级到“空间服务品牌”高级感。

## 1. 总体影像定位

关键词：**真实空间 / 安静秩序 / 城市生活 / 温润克制 / 可信安全**。

不要：房地产样板间、极端 HDR、强饱和绿色、夸张广角、纯 Logo 图、明显 AI 建筑、廉价电商促销构图。

## 2. 摄影基准

- 等效 24–35mm 室内空间视角；避免鱼眼。
- 机位高度约 1.4–1.6m，保持真实到店体验。
- 竖线尽量垂直，门体与走廊保持秩序感。
- 白平衡中性偏暖，不把仓库拍成冷蓝工业空间。
- 品牌绿只作为局部识别，不要求大面积出现。
- 曝光优先保住墙体、仓门、灯带细节。
- 人物如出现，以整理、搬入、取物为真实动作，不直视镜头摆拍。

## 3. 必备资产槽位

### A. Home / H01 Brand Hero
- 用途：首页首屏、品牌氛围。
- 推荐比例：4:5 原图；前端可裁 0.78–0.9 宽高比拱门 Mask。
- 内容：干净走廊 / 仓门入口 / 真实储物空间。
- 安全区：主体尽量位于画面中右 60%，便于左侧标题。

### B. Store Hero / S02
- 用途：门店详情主视觉。
- 推荐原图：3:2，至少 1800px 宽。
- 必备：每家重点门店 2–4 张。
- 第一张负责空间印象；后续图可展示入口、走廊、电梯/搬运条件。

### C. Store Card / H01 + S01
- 用途：首页与附近门店推荐。
- 推荐原图：16:9，可安全裁到 16:7 / 16:6。
- 禁止在图内嵌价格、文字、角标。

### D. Unit / Warehouse Size
- 用途：S02 / U01 仓位理解。
- 每种典型容量至少准备 1 张“空间感”图，不要求每个真实仓位单独拍摄。
- 图像必须明确是“仓位环境示意”或真实对应门店图，不能让示意图看起来像唯一真实物理仓位。

### E. B2B / Business
- 用途：商家企业入口与后续内容。
- 场景建议：库存箱、样品架、资料箱、设备/物料。
- 不使用夸张电商仓库、自动化立体仓等与当前服务不符的场景。

### F. EStore
- 当前无独立详情页，不新增页面。
- 未来资产方向：上门取件、RFID 标签、标准周转箱、物品清单，而不是再拍一组门店走廊。

## 4. 色彩后期

- 高光偏暖白，阴影保持中性。
- 饱和度整体降低约 5–12%。
- 绿色允许轻微统一，但不能把墙体/仓门整体调绿。
- 推荐使用“真实材质 + 轻暖纸色”的品牌观感，与 `#FAF8F3 / #183E30 / #C86424` 协同。

## 5. 文件与命名

建议：
- `store_<store_id>_hero_01.webp`
- `store_<store_id>_card_01.webp`
- `unit_demo_<volume_band>_01.webp`
- `b2b_inventory_01.webp`
- `estore_pickup_01.webp`

交付格式：WebP 优先，保留原始 JPG/RAW 归档。

## 6. 导出性能

- 首页/列表卡：建议单张 ≤ 220KB。
- 门店 Hero：建议单张 ≤ 320KB。
- 2x 输出优先；根据小程序图片 CDN 再生成多规格。
- 禁止水印、拍摄时间、地图截图等嵌入图像。

## 7. 真实性规则

1. 真实门店照片可直接作为事实资产。
2. 非真实门店图只能作为“环境示意”，不可暗示为具体门店实拍。
3. AI 图只适用于品牌氛围、空状态、概念插图，不作为门店设施事实证据。
4. 品牌荣誉、门店数量、服务设施等事实仍需来自正式数据源，不由图片“创造”。

## 8. 资产验收

每张进入生产候选的图片必须通过：
- 清晰度
- 透视不过度
- 无敏感个人信息
- 无其他品牌标识干扰
- 无虚构设施
- 移动端 375px 裁切可用
- 亮部/暗部细节完整
- 与整套 V2 视觉色调一致
