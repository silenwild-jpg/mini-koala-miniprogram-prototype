## 1. 统一口径与适用范围

V1.1.1 负责基础颜色、文字、按钮、标签、价格与交互规则；本补充负责首页新用户态的生活实景、物品配图、考拉元素、留白与信息减负。其他首页状态继承哪些内容，应在对应状态任务中验证。

执行时共同使用 V1.1.1 与本补充；有冲突时，首页表达按本文明确的修订项处理，业务规则、价格语义和操作行为仍按当前母版。历史规范作为版本记录，不重复叠加使用。生图仅是视觉参照，不作为颜色、文字、尺寸或事实来源。

## 2. 沿用的基础规则

| 项目 | 执行口径 |
|---|---|
| 页面／表面 | 页面近白 #F8FAF9，卡片白 #FFFFFF；次级表面 #F3F6F4 |
| 品牌与价格 | 主绿 #2F6B4F；主价格橙 #D56A1C；浅橙底促销小字用 #A04E12 |
| 文字 | 正文优先 14–16px，说明 13px，辅助及可见信息不低于 12px；不得为缩短页面而缩字 |
| 对比度 | 普通信息文字含占位 ≥4.5:1；符合大文本条件的价格 ≥3:1，检查实际背景 |
| 灰色文字 | #6D7671 仅用于通过验证的白色表面；灰底／浅色背景上的辅助文字优先 #59645E |
| 按钮与点击 | 主按钮沿用 48px 基准；链接及紧凑入口保留可用点击区域、明确状态与可访问名称 |
| 圆角与标签 | 门店卡沿用 14px、按钮 12px；仓型标签胶囊、服务／促销标签 6px；不机械统一所有元素 |
| 价格与业务 | 保留单位、起价、参考口径、优惠计算、推荐、库存、路由与状态机 |
| 技术底座 | 复用 --koala-*；只增加所需页面作用域；不扩展全站别名，不开展历史 CSS 删除 |

绿色集中承担品牌、主要行动和选中状态。减少大面积绿底及普通说明中的绿色强调。新增浅蓝／浅杏仅用于图片底衬和少量任务卡，不承担新的状态含义；具体实现值需检查文字对比度后记录。

## 3. 首页生活感表达

### 图片与考拉

- 首屏使用自然光、简洁收纳场景；优先沿用已确认的生活配图方向，文字区域保持清晰。
- 首屏出现一处小考拉，低于标题和主要操作的视觉权重；不遮挡文案，不反复出现在其他模块。
- 生成考拉属于设计概念；正式 Logo 使用现有品牌资产，IP 落地前核对来源及正式使用口径。
- 门店使用真实门店照片。生成图中的仓门照片不能代替真实资料，也不通过改变仓门颜色减绿。
- 六个场景配图统一视角、光线、材质和大小；不将生图中的 UI 中文烘焙进配图。

### 两类图形各司其职

| 类别 | 表现 |
|---|---|
| 内容配图 | 场景物品、计算器、地图等可用柔和的立体物品表现，帮助理解用途 |
| 操作图标 | 返回、导航、筛选、电话、客服等继续使用清晰线性图标，保留可访问名称 |

### 卡片与留白

门店、任务等独立对象可保留卡片。场景、流程、品牌统计及保障更多依靠排列、留白和轻分隔线；取消每一项都加外框和阴影的做法。每种组件保持自身一致，页面之间允许按任务使用不同展示变体。

## 4. 首页组件与内容融合表

| 区域 | 采用方向 | 保留边界 |
|---|---|---|
| 首屏与双任务 | 生活实景、小考拉、浅色任务卡、小面积绿色行动区 | 两项任务与原有点击路径；整卡可点，不增加第二次确认操作 |
| 推荐门店 | 一张主推荐＋两张精简备选；主卡上图下信息 | 三卡数量与推荐逻辑；第二、第三张不恢复库存／容量 |
| 价格区 | 橙色数字＋灰色单位；按实际宽度排版 | 不照抄生图中单位换行或价格语义偏差，不缩小单位解决空间问题 |
| 六个场景 | 六张统一物品配图，减少边框和重复副文案 | 六种用途及入口；副文删除逐项记录，不能影响用途理解 |
| 企业入口 | 紧凑浅底入口 | 原有企业需求路径与必要适用信息 |
| 四步流程 | 保留当前位置，压缩为轻量行 | 不迁移到双任务下；保留完整步骤含义，不改变业务流程 |
| 品牌统计与保障 | 开放分组、轻分隔线，减少独立小卡 | 使用已核实事实；不增造数字、承诺或适用范围 |
| 荣誉 | 压成轻量资料入口 | 先核对详情页内容去向；未核验材料不得改成已获认证 |
| 导航与帮助 | 沿用基础样式；帮助采用紧凑入口 | 不出现遮挡价格的全宽空白帮助条；可见、可点、可关闭 |
