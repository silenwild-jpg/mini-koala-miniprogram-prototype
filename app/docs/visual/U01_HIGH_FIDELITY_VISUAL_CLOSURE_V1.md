# U01 High-Fidelity Visual Closure V1

## Sprint 1F — U01 仓位与价格

**基线：** Mini Koala Prototype Baseline 1.0  
**视觉系统：** Mini Koala Visual Design System V1  
**执行性质：** VISUAL PATCH / 非 REDESIGN

## 1. 本轮视觉目标

把 U01 从“信息齐全的业务原型”收口成明确的订单前决策页，建立以下视觉链：

**仓位身份 → 租期 → 整期总租金 → 月租 / 折扣 → 押金 / 管理费 → 预计本次应付 → 继续租用**

本轮不修改价格计算、押金、管理费、搬运资格、订单路由、文案或交互逻辑。

## 2. 视觉调整

### 仓位身份
- 仓位入口示意收进 16px 圆角 Surface。
- 容量数字提升为身份主标题。
- 仓号弱化为右侧胶囊信息。
- “特价”使用轻量状态胶囊，避免促销 Banner 化。

### 租期选择
- 当前租期变成清晰摘要卡。
- 1–60 月快捷项统一为标准选择按钮。
- 折扣角标收进按钮内部并保持单行。
- 自定义租期步进器统一到 44px 可点击尺寸。

### 价格层级
- 整期总租金为唯一主价格：暖橙、大字号。
- 月租降为第二层解释价格。
- 当前租期折扣改为弱绿色小胶囊。
- 押金与管理费作为费用明细。
- “预计本次应付”单独放入浅暖橙摘要行，但视觉仍低于整期总租金。

### 空间尺寸
- 长 / 宽 / 高统一为中性事实卡。
- 门口尺寸、仓位形态、所在位置使用稳定列表结构。

### 搬运支持
- 使用暖米色辅助 Surface。
- 不与主价格、主 CTA 竞争。
- 搬出地址与确认距离保持原交互不变。

### 底部决策
- “需要帮助”保持次级 Outline。
- “继续租用”保持唯一主 CTA。
- 全局帮助入口上移，避免压住底部决策区。

## 3. 不变项

- `<body>` 字节级一致。
- 中文文案不变。
- 价格公式不变。
- 押金 = 1 个月租金不变。
- 管理费 ¥50 不变。
- 租期折扣规则不变。
- 搬运资格逻辑不变。
- Q01 / O01 跳转参数不变。
- 顾问与看仓交互不变。
