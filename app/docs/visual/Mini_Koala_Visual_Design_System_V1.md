# 1. 视觉定位

## 核心气质
**城市生活型仓储 · 清爽可信 · 有温度 · 克制专业**

关键词：
- 邻里感
- 安全可靠
- 性价比
- 清爽
- 易理解
- 城市生活服务
- 轻生活方式感

避免：
- 工业仓储感
- 重金融感
- 电商大促感
- 大面积品牌绿
- 过度卡通
- 过度科技感
- 过度奢华

## 视觉决策原则
1. 信息优先于装饰
2. 价格只允许一个最高视觉层级
3. 绿色负责品牌与行动，不负责填满页面
4. 暖橙只负责价格
5. 卡片用于信息分组，不制造“层层套卡”
6. 单卡标签最多 3 个
7. 视觉问题只用视觉方式解决，不改业务结构
8. 375×812 为第一设计尺寸，390×844 为第二验证尺寸

# 17. 状态组件

## NOMATCH
目标是“可恢复”，不是错误。

视觉结构：
- 中性图标
- 明确标题
- 一句话解释
- 主 CTA：调整需求
- 次级：考拉E存 / 客服 / 接近方案

禁止使用强红错误态。

## Empty
中性图标 + 简短说明 + 1 个行动。

## Loading
优先 Skeleton。

## Success
使用品牌绿，但避免大面积庆祝动画。

# 18. 图片系统

门店图片风格：
- 真实
- 明亮
- 微暖
- 空间整洁
- 色彩克制

优先：
- 走廊
- 仓门
- 储物空间
- 用户可理解的场景

避免：
- 过度 HDR
- 过度 AI 建筑感
- 纯 Logo 图
- 高饱和绿色空间

建议比例：
- 首页主推荐：16:7
- 普通门店卡：16:6

若非真实门店照片：
统一标识“门店环境示意”。

---

# 19. 图标系统

风格：
- 线性
- 圆角
- 约 2px stroke

尺寸：
- 16px：弱辅助
- 20px：正文操作
- 24px：主要功能
- 28–32px：首页任务入口

禁止 Emoji / 实心 / 线框 / 卡通混用。

---

# 20. 移动端规范

主设计尺寸：
**375×812**

第二验证尺寸：
**390×844**

固定规则：
- 页面左右边距 16px
- 主按钮高度 48px
- 禁止桌面双栏式主视觉
- 标签可在标签之间换行，但标签内部不换行
- 地址默认单行省略
- 浮层不得遮挡价格和 CTA

---

# 21. 动效原则

只保留功能性动效。

推荐时长：
- 快速反馈：120–160ms
- 页面状态：180–240ms
- Modal / Sheet：240–320ms

禁止：
- 自动闪动价格
- 强弹跳
- 长时间装饰动画
- 无业务意义的大面积动态效果

# 23. 页面高保真验收标准

每页必须通过四层：

## Structure Diff
- DOM 主结构不变
- 模块数量不变
- 文案不被润色
- CTA 不变

## Visual QA
- 品牌绿不过量
- 主价格唯一
- 标签不堆积
- 主次卡层级清楚
- 页面节奏统一

## Device QA
375×812 / 390×844：
- 横向溢出 0
- 遮挡 0
- 标签内部折行 0
- 浮窗覆盖核心价格 / CTA 0

## Interaction QA
- 推荐逻辑不变
- 折扣逻辑不变
- NOMATCH 不变
- EStore 不变
- URL / 状态 / 参数不变
