# Sprint 2 — Transaction High-Fidelity Closure V1

**母版：** Mini Koala Visual Baseline 1.0 — FROZEN  
**范围：** Q01 保存方案 / O01 确认订单 / O02 订单结果 / O03 订单详情  
**性质：** VISUAL PATCH；不改 Body、文案、金额、状态、生命周期或跳转。

## 1. 视觉目标

交易链不再承担营销页的视觉任务，统一收口为“可信、透明、稳定”的交易服务体验：

- Q01：方案可以找回，但不制造“锁价/锁仓”误解；整期总租金为主要价格。
- O01：本次应付为唯一支付主视觉；费用拆分清楚且可核对。
- O02：成功 / 待支付 / 失败 / 库存变化使用清晰状态层，不改变原有恢复路径。
- O03：订单状态、仓位、租赁信息、协议付款、租期管理形成稳定的信息层级。

## 2. Q01 保存方案

- 页面顶部改为中性交易页 Header。
- “稍后继续也方便”使用浅绿辅助胶囊，不作为促销。
- 月租降级为辅助信息。
- **本租期总租金**提升为 30px 暖橙主价格。
- 费用明细恢复为中性列表，不使用连续色块。
- 方案说明使用浅绿可信说明 Surface。
- 运输支持使用浅暖橙弱提示。
- 联系方式与输入框统一至 48px 表单标准。

## 3. O01 确认订单

- 仓位身份与租期信息保持白色事实卡。
- **本次应付**升级为 34px 暖橙唯一主价格。
- 整期租金、月租、押金、管理费、运输均降为费用明细。
- 支付后说明使用浅绿 Supporting Surface。
- 存放须知采用暖米色风险说明，而非红色警告。
- 协议区恢复为白色中性确认区。
- Bottom CTA 保持“返回查看仓位 / 确认并支付”的主次关系。

## 4. O02 订单结果

- 状态 Hero 统一为卡片化结果区。
- 支付成功：绿色；待支付：暖橙；支付失败：红色；库存变化沿用恢复态语义。
- 实际已支付 / 待支付 / 应付金额统一为 30px 暖橙价格主视觉。
- 仓位身份、订单号、状态保持中性事实列表。
- 身份验证 / 密码区使用浅绿服务 Surface。
- 替代仓位恢复区保持现有业务逻辑，仅统一按钮与卡片视觉。

## 5. O03 订单详情

- 生命周期状态收口为独立状态 Hero。
- 仓位信息成为订单详情的第一事实区。
- 导航到店 / 仓位密码 / 联系门店统一 44px Outline Action。
- 租金合计、实际支付使用价格橙，但不与页面标题竞争。
- 协议 / 付款 / 发票 / 押金、续租 / 退租统一为 62px Action Card。
- 运输权益使用浅绿服务 Surface。
- 推荐有礼保留深绿独立营销卡，但不进入核心交易价格体系。

## 6. 冻结边界

本轮明确未修改：

- Q01/O01/O02/O03 `<body>` 内容
- 中文文案
- 订单字段
- 租期与价格计算
- 押金 / 管理费
- 运输资格
- 身份验证
- 支付结果状态
- 库存变化恢复路径
- 生命周期状态
- 页面跳转与 localStorage/REPO 行为

## 7. 设备标准

375×812 与 390×844 均为必测尺寸。
