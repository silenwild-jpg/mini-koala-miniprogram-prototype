# UX-PATCH D1｜推荐一致性、返回协议与首仓直达修复交接

日期：2026-10-14  · 基线：UX-PATCH C（SHA256 `887b08c05976d57cbd24482339f88e871f0d0eab12ddfb50b1e0e8fea9d50c16`）

## 一、实施范围与业务语义

1. **推荐展示策略一致**：S01 与 S5 共用 `mini_koala_recommendation_policy_v2.js` 的 `highlightRanked`。最近门店以驾车/所选出行距离为准；“区域低价”以 3 公里为默认比较范围（S01 距离筛选可动态改变）；同一家最近且最低价时不把其他门店错标为区域低价。S5 使用 `recommend()` 实际返回的可售单仓/组合推荐集合与真实整期总租金排序。推荐卡显示最多两家门店，考拉E存仍为独立方案；不替代原有价格逻辑、真实库存或特殊筛选。
2. **S5 底部首仓直达**：从当前显示的推荐集合挑选第一条 `matchType==='single'`、含明确物理仓位 ID 且 `available_count>0` 的结果，点击主按钮跳 U01（门店、仓位、规格、容量、租期、搜索上下文不丢失）。不使用用户上次点击的第二张卡作为首选。若仅有组合方案进入对应 S02 组合承接，不伪造单仓；无确切匹配或只是相近容量时进入 S01 恢复流程。
3. **显式返回**：S5→U01 与 U01→S02 都传递 `returnTo=S5`；S02 从 S5 出发的相关详情、查看其他仓位和导航降级页都提供 S5 返回。S02 再点仓位进入 U01 仍传递 `returnTo=S5`。已有 `mini_storage_estimator_return_snapshot` 保存场景、容量、用户租期、选仓偏好和结果状态；进入 `entry=resume_usage` 恢复有效状态，不覆盖已有租期为 12 个月。
4. **保留边界**：不修改价格、押金、管理费、优惠券、支付、订单、库存、估算 45 图和 5m³ 分流；组合仓仍用原页面承接。D2 的首页顶栏、左右间距、三个快捷入口位置及全站底部 CTA 本轮未修改。
