# Mini Koala — Combo UX Regression PATCH V2｜实施与验收记录

日期：2026-10-12  
基线：`Mini_Koala_Combo_Demo_UI_Price_Fix_V1_Candidate.zip`  
状态：**内部演示候选；Release Gate HOLD**。

## A｜推荐合理性与过小仓位准入

- 同店组合推荐增加 1.30 倍容量上限：与用户需求目标相比，组合容量不得明显超额；在搜索阶段剪枝，不对超额组合继续扩展或展示。1.30 是演示规则，不作为永久商业定价规则。
- 取消 S02 `nomatch` 状态将远小于需求的单仓以“更紧凑”直接作为主推荐并跳转 U01。无可行单仓、无合理组合时使用附近门店入口。
- 高价值场景只展示处于需求范围内的可租仓位；`查看更多仓位` 在已携带需求时只可继续展开真正匹配的单仓。
- 仓位卡添加容量下限守卫；低于需求的卡片即使意外出现在列表，也无法从整卡、CTA 或延长租期入口绕过至 U01。普通浏览不受此守卫影响。
- 调整需求后重新判定 `matched/nomatch`，避免页面标题、卡片和底栏按钮状态不一致。

## B｜跨页上下文与操作可达

- 在 S01 的售罄门店入口保存当前目标容量、租期、搜索位置、驾车/步行方式、排序、距离和服务筛选；无估算需求的浏览状态保持 `browse`。
- S02 售罄主按钮、附近门店入口及组合兜底共用一个返回路径，携带对应用户需求和筛选上下文，不要求用户重新估算。
- S02 底栏“查看组合方案”定位至**卡内“咨询此组合”按钮**，保留其上方组合价格和组成信息；固定底栏上方具备安全间距。`highvalue` 状态也使用同一逻辑。

## C｜组合咨询与状态传递

- S02 组合咨询在手机号已存在或新录入成功后展示 `已保存 XXm³ / X间仓组合需求`；保留最新组合/顾问上下文字段。显示“联系客服”按钮，使用原有微信客服演示入口，不创建新客服能力、不重复索要手机号。
- S5 推荐卡映射补传 `fitStatus`，与 S01/S02 的适配状态字段一致，不增设冗长尺寸说明。
