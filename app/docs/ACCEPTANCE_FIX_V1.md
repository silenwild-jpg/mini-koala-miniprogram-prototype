# 迷你考拉仓 · 验收修复版 V1（尺寸说明删除更新）

根据最新指令，已删除仓位方案中的“大件尺寸待确认”区块，并同步删除估算推荐、门店、仓位方案和确认订单中的尺寸待确认说明、标签与关联按钮。

仓位方案主按钮恢复为“继续租用”，长件可按常规演示流程进入确认订单。原尺寸确认前的下单及付款拦截同步取消，避免说明删除后出现无反馈的阻断。自定义物品的尺寸数据和“修改尺寸”能力保留。

其他验收修复继续保留：需求取消回滚、容量加减边界、到店演示指引、库存失败恢复、邮箱与重复发票校验、退仓日期校验、企业电话校验、搬运权益入口、辅助字号、点击区和键盘交互。

## 使用

完整解压，打开 `START_HERE.html`。截图索引在 `outputs/Acceptance_Fix_Gallery.html`。

如需HTTP预览，在解压目录运行 `python -m http.server 4173`，打开 `http://127.0.0.1:4173/START_HERE.html`。

检查命令：`python qa/run_acceptance_static.py`；安装Playwright与Chromium后运行 `node qa/test_acceptance_fix_runtime.cjs`。自备Chromium可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。

此包仍为演示原型。价格算式沿用已复核口径：2390−200＋398＋50＝2638；6400−300＋533＋50＝6683。
