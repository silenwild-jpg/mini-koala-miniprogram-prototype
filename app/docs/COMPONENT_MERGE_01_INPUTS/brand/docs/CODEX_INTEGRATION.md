# Codex 集成任务｜BRAND-VIS-01C

## 目标
在当前正式候选的 **首页单一品牌区块** 中安装 `brand-section.html` 及 `css/brand-vis-01c.css`，使用 `assets` 图片分拆资源。目标风格已由用户视觉定稿，不能将整个设计稿一图嵌入。

## 开始前
- 仅以用户明确指定的最新 ZIP 作为唯一母版，核对 SHA-256、ZIP CRC、Release Manifest；若出现多候选或哈希冲突则停止并报告。
- 定位原有品牌区标题“城市仓储领先品牌”、三项数据、四项服务、品牌资料区。
- 保存现有区块与“了解更多”的行为、任何条件/状态逻辑、布局原始样式。

## 执行
1. 在对应首页 DOM 单独换入 `brand-section.html` 内容，避免影响其他首页区块和 DOM 选择器。
2. 保持原品牌事实文案、三项关键数值和四项服务现有准确数据；本包文案须与最新原型比对，冲突时以经确认业务口径为准，并报告差异。
3. 在原首页加载 `css/brand-vis-01c.css`，检查样式冲突、z-index、滚动与隐藏状态；CSS 应仅作用于品牌区。
4. 将四张 demo WebP 加至现有静态素材目录（建议 `assets/brand/`），修改 HTML 路径。不得更换其他首页图。
5. 唯一保留“了解更多”跳转；沿用原函数/原路径，不能改用 demo 占位跳转。
6. 底部无“品牌资料”主标题、无“查看资料”链接、无“材料待核验”文字；展示仅三张图片，图片下方分别 `高新技术企业`、`CCTV报道`、`国标起草单位`。
7. 顶部图片、三数字、四服务、三资质均保持可在源码中独立编辑。不要把整块 HTML 截屏作位图背景。
8. 保持 Release Gate = HOLD。

## 安全边界
底部3图为演示模拟，不构成企业资质证明。正式发布前必须换为授权且经证实的真实图片；否则移除此区块。不要把模拟证明文件当真实的企业资格或国家标准参与事实。

## 验收
- 375×812、390×844、DPR2、zh-CN 真 Chromium 截图；无横向溢出、无字重叠、图片无扭曲、标签不截断。
- 核对原首页上/下相邻模块、路由及其余页面未变；主文案 14年、590+、30万+、4项服务、3项资质展示完整。
- “了解更多”触发原有跳转，不出现新死链。
- 复核 ZIP 解包 CRC、Manifest、所有改动路径、每项文件 SHA；输出新候选和改动清单。
- 回归结论区分 PASS/FAIL/BLOCKED/NOT TESTED；禁止把静态预览通过写成全站通过。
