# NAV-ICON-01B｜方案 B 四图标双状态精修与 SVG 交付

- 项目：迷你考拉仓—统一项目
- 版本：NAV-ICON-01B / 2026-10-15
- 设计基线：用户已选择 NAV-ICON-01A 方案 B（品牌强化 · 柔和圆角 · 仓储元素）
- 本包性质：**可编辑图标资产 + 独立设计验收预览**，非已合并的业务原型
- 原型及发布状态：**未修改最新原型包；正式发布 Release Gate 仍为 HOLD**

## 1. 四个入口的识别语义（冻结）

| 入口 | 图标对象 | 易理解的含义 | 避免事项 |
|---|---|---|---|
| 首页 | 房屋屋顶 + 卷帘仓门 | 品牌首页、业务入口 | 不再用纯住宅门替代仓储门 |
| 找仓 | 仓箱 + 放大镜 | 按需求、容量、价格找仓位 | 不再用孤立放大镜；避免和门店导航混淆 |
| 门店 | 实体门店店招 + 定位图钉 | 查看实体门店、附近位置 | 不用与「找仓」相同的箱体图形 |
| 我的 | 通用人像 + 小仓箱 | 我的账户及用仓服务 | 不用卡通动物取代用户中心通用认知 |

四枚标志的商业语义要明确区分：找仓是找可租方案；门店是找真实线下门店。标签沿用现有原型：**首页、找仓、门店、我的**，不可改名或调整顺序。

## 2. 图标标准

| 项目 | 冻结参数 |
|---|---|
| 绘制网格 | 24 × 24 viewBox |
| 导航图标尺寸 | 推荐 26 CSS px，范围 24–26px |
| 默认线宽 | 1.8 svg 单位；细节辅助线 1.4–1.65（已在路径中指定） |
| 线条处理 | stroke-linecap=round；stroke-linejoin=round |
| 未选中颜色 | #78847E，灰绿轮廓；原则上透明填充 |
| 选中主色 | #176949，品牌深绿 |
| 选中辅助色 | #B7DEC6，较浓的浅绿点缀 |
| 选中底色 | #E3F3E9，浅绿色面积填充 |
| 标签文字 | 推荐 12px；选中 600–700 字重，未选中常规字重 |
| 图标至文字 | 4–5px |
| 容器背景 | #FFFFFF，顶部 1px 极浅分割线 |
| 导航高度 | 内容区约 60–64px，底部另叠加设备安全区；不要把安全区挤占内容区 |
| 可点击区域 | 推荐每项至少 44×44 CSS px，实际整列可点 |

颜色按原型具体 Token 映射时只替换 CSS 变量，不要出现一个页面中有两种「品牌绿」。图标资源自身是固定色 SVG；如需动态主题可让 Codex 将路径抽取至共享组件（保持相同构图）。

## 3. 资源映射（不可错配）

| 页面 | 未选中 SVG | 选中 SVG |
|---|---|---|
| 首页 | `svg/home-inactive.svg` | `svg/home-active.svg` |
| 找仓 | `svg/find-inactive.svg` | `svg/find-active.svg` |
| 门店 | `svg/stores-inactive.svg` | `svg/stores-active.svg` |
| 我的 | `svg/me-inactive.svg` | `svg/me-active.svg` |

同时提供透明背景 `png_2x/`（48×48）和 `png_3x/`（72×72）。小程序原生 tabBar / 目标客户端对于 SVG 在图标路径中的支持情况可能有所差异：必须在实际技术栈中验证；不支持则使用等比 PNG 资源，不允许把截图裁切为图标。

## 4. 双状态一致性与关键验收

1. 统一全站共享底部导航组件，不要在首页、找仓、门店、我的四个页面各复制样式。
2. 四个页面正常进入时，只有当前入口对应的图标、文字显示选中态，其余 3 个均为未选中态。
3. 从子页返回、前进、订单支付前返回、打开后重新进入、刷新后均恢复正确状态；不要按照最近点击缓存错误高亮。
4. 375×812、390×844，DPR 2，分别检查图标中心、字重、间距、底部安全区和窄屏视觉均衡。
5. 弱网、资源路径失败时，不应影响导航点击与页面功能。提供可验证的降级资源策略。
6. 不触及业务规则、支付前交易链、报价和优惠券，也不调整导航命名、顺序或跳转目标。
7. 截图比对检查：首页、找仓、门店、我的各至少 1 组激活态 + 另一入口未激活态。

## 5. 文件内容

- `svg/`：8 个独立标准 SVG（透明背景，24×24 viewBox）
- `png_2x/`、`png_3x/`：8 枚图标的透明 PNG 等比降级资源
- `index.html`：独立零依赖可交互预览；建议使用本地 HTTP 浏览（`python -m http.server 4173`），部分客户端会拦截 `file://`
- `previews/`：设计验收总览图、375／390 逻辑宽示意截图
- `docs/`：设计规范与 Codex 受控试装交接
- `manifest.json`：文件散列清单用于交接校验

## 6. 边界说明

本轮视觉预览的上下文页面属于重新绘制的示意 UI，**不是**原型业务界面的真实浏览证据。SVG 文件是可直接复用的设计资产，但上线前仍必须确认实际端对 SVG / PNG 的支持与显示情况，并对完整业务原型做双尺寸真实浏览验收。正式合并留待 NAV-ICON-01C。
