- 使用 DOM 文本级映射和动态节点观察，不变更原始交易数据、存储键、URL 参数、价格函数、协议状态、券规则或订单分配流程。

## 用户端修改范围
1. **AF-12 内部技术与演示措辞**：用户可见订单/方案 DEMO 编号使用稳定的仅展示别名（底层 ID 不变）；`term_months`、`shareId` 等若出现在正常文案中改为自然语言。原始网址及其查询参数不会被替换。
2. **内部评审区隔离**：默认用户视图隐藏 `.review-only`、`.review`、`.stagebar`、`.review-tools`，内部 QA 可在当前页面增加 `?showQA=1` 查看原有评审字段、调试控件和场景状态。内部 Demo Hub / D01 不进行文案覆写。
3. **AF-13 日期显示**：面向用户的独立文本节点将 `YYYY/MM/DD`、`YYYY-MM-DD`、美式 `M/D/YYYY` 转为 `YYYY年M月D日`，美式 `12-hour AM/PM` 转为 24 小时；仅影响可见文案，不更改存储值和真实日期计算。
4. **AF-14 证据措辞风险**：暂不对外展示“（行业唯一）”限定词，保留高新企业认证及证书素材原位；展示素材及可用事实仍须由业务核验，不把示意占位当成真实认证证明。
5. **AF-16 文案优化**：发票申请、押金说明、用仓前身份验证、运输权益、退租续租期限说明等使用用户语言；不添加任何退款到账时间、开票 SLA、新折扣、锁仓承诺。
6. **AF-17 术语统一**：`看仓预约→预约看仓`；自选月份说明改为 `其他租期（1–60个月）`；进一步去重布局留至 PATCH D。
7. **AI 示例透明**：AI01/AI02 文案使用“示例识别流程”等表述，不暗示已调用真实识图服务；保留使用和隐私提醒。
8. **未开放入口说明**：运输预约、旧报价记录、旧合同页等仅保留“不支持在线办理、返回首页”的说明；返回链接导向实际 H01 首页，不增加新业务能力。

## 显示层边界
- **内部 ID 别名仅供界面演示**：底层 `O-DEMO-*`/`Q-DEMO-*` 留作原型的订单检索、存储关联与测试 fixture。UI 别名不是可用来通过后台查询的真实订单号；正式上线必须由后端生成并展示一致编号。
- **协议页面仍为非正式示例**：不把原型摘要冒充正式法律合同。正式对外发布前由业务和法务确认。
- **复杂营销承诺不擅改**：推荐奖励档位与好友首单加赠等具体商业规则未获新批准，本轮不改变数值，不把本次文案清理当成法务或营销审批。
- **素材保持现状**：证书图片现阶段仍是示意占位；不能以“去除占位角标”的方式冒充真实文件。AI 图片仅供示例。
- **内部调试与用户视图分离**：`showQA=1` 仅切换控件显示，不影响场景 / 订单数据。
