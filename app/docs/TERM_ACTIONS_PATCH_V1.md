# 租期与推荐底部按钮 PATCH V1

已修改原型页面：prototype/space_decision_assistant_v4_5_23_self_service_synced_Visual_V2_7_4.html。

## 修改
- 底部由三入口改为两按钮，左104px次按钮、右侧自适应主按钮，间隔12px，高48px。
- 正常匹配：顾问协助 / 查看推荐仓位；上方提示当前推荐门店。
- 无匹配：调整需求 / 顾问协助；调整需求定位到容量加减，不自动修改用户容量。
- 未选租期：保留单个请选择租期按钮，不展示更多门店入口。
- 更多符合需求的门店移到推荐区标题右侧；无匹配时使用查看附近门店，避免误称匹配。
- 门店列表入口仍携带容量、租期、用仓位置及既有筛选上下文。
- 浮动帮助仅在此页隐藏，顾问入口承接人工协助；其它页面不受影响。
- 保留原有推荐卡点击直接进入仓位列表行为。
