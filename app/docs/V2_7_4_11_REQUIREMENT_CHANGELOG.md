# V2.7.4.11 需求补丁变更说明

## 数据与价格口径

- 门店、仓位编号、容量、可租数量及价格继续以正式母表生成的 `mini_koala_data.js` 为唯一前端事实源；页面脚本不复制事实数据。
- `size_unit` 确认为 `m³`。面积按 `体积 ÷ 2.5m` 换算；长、宽按等边地面面积推导，高度统一为 2.5m。
- 首页推荐与估算推荐统一显示整数口径的“XX元/月/m³起”。进入门店及仓位后，根据所选仓型和租期展示价格；未选租期时按该仓型 1 个月租金展示。
- `has_zero_price=true` 或展示价不大于 0 的档位与仓位不进入前端可选集合，也不显示“0元/月”。

## 核心路径

- Estimator → S01 → S02 → U01 统一读取生成数据源，推荐卡使用确定的仓位容量、仓位编号和租金，不再展示固定门店、固定 8 个仓位或固定容量范围。
- 未填写需求时，门店页“立即估算”回到“找合适空间”起始页。
- 已关联需求时，S01 与“租期与推荐”使用一致的单仓匹配逻辑；S02 首个推荐卡增加“需求接近”，宽裕卡增加“存取更方便”。
- “租期与推荐”的推荐仓体与租金改为单一确定值；底部“邀请协助”作为客服/销售介入原型入口。

## 页面清理

- 首页更新场景入口、服务保障文案及首页推荐价格格式。
- 存储用途“收藏保管”改为“爱好收藏”。
- S01 浏览态删除重复“附近门店”角标，显示“剩余仓位”和真实容量范围，并保留社区仓/超级仓单一类型标签。
- S02 删除门店位置区块、旧说明、展示数量摘要和“价格怎么计算”；“到店与搬运”上移并默认展开，“设施与服务”保留六个主标签且默认展开。
- S02 将“查看更多仓位”作为最后一张初始仓位卡后的加载入口；删除重复仓号和无匹配提示。
- U01 删除“和您的需求匹配”区块，并显示由数据源生成的容量、面积和长宽高。
- 看仓文案更新为支持远程/实地看仓与免费预约。

## 企业页、订单与服务入口

- 企业页支持存储类型多选、“其他”补充、5 年租期、称呼、预计用仓日期及补充信息；需求提交后携带上下文进入“租期与推荐”。
- 免费首次搬运沿用通用规则：选择需要搬运、租期大于 6 个月且距离大于 5 公里时展示。
- 订单页移除联系方式区块；确认支付前展示可验证的微信手机号授权原型。增加用仓时间、到期时间及押金说明弹层。
- 全部 43 个完整 HTML 页面接入右下角电话与在线客服浮窗。电话为 4000358805；在线客服当前为可验证原型弹层，生产版需替换为微信客服能力。

## 保留项与边界

- 用户需求第 23 条“附近门店卡片：主标题为”未给出目标文案，因此保留当前主标题，不擅自补写。
- 两个历史参考片段没有完整 `body` 结构，不作为可运行页面，也未注入全局客服脚本。
- 当前长宽高为原型推导值，不代表真实测量；待补充真实尺寸后应从生成数据源统一替换。
- 本轮不包含真实微信授权、微信客服、地图、库存、支付或交易接口接入。
