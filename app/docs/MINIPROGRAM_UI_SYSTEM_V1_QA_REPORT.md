# 迷你考拉仓小程序 UI System V1 — 实施与验收记录

2026-10-12｜母版 `Mini_Koala_Recommendation_External_AI_Fix_PATCH_V2.zip`｜新 ZIP 为完整增量母版，非只含 CSS 的补丁。

## 实施结论

- 将独立共享 CSS `prototype/mini_koala_miniprogram_ui_system_v1.css` 应用于 H01、S01、S5、O01 四个现有 HTML 页面。
- 背景试装采用低饱和近白 `#F8FAF9`，卡片为白色，品牌绿作为操作焦点，橙色强调价格。
- 规范搜索位置框、筛选选中反馈、服务标签单行展示、门店卡框线/价格、推荐态、支付底部安全区与焦点可见性。
- 不重写现有推荐、数据、价格、库存、订单或跳转函数；核对发现旧 HTML 只有 `<link>` 和 `<body class>` 两处插入，其余源码字节保持一致。
- CSS 为浏览器演示样式，不是可直接复制至微信小程序的 WXSS 源码；未来开发参照组件映射规范转写。

## 推荐给评审同事的复验顺序

1. 双屏宽打开 H01→S01→S02→U01→O01；H01和S01的默认前两门店应同源；筛选半径/暂无候选不回归。
2. S01 检查三个下拉是否跟随锚点弹出、无文字折行和溢出；检查定位/携需求两种价格口径。
3. S5 从估算切换租期与容量，动态刷新推荐，确保所有方案对应同一订单报价。
4. O01 检查费用汇总、优惠券选择、按钮可见性、底部安全区和返回保存状态。
5. 微信开发者工具检查 375×812、390×844 对应模拟设备与真机；通过后再考虑 Release Gate 解冻。
