日期：2026-10-12  |  状态：**内部演示候选 / Release Gate HOLD**

## 1. 母版与边界

- 唯一输入母版：`Mini_Koala_Homepage_State_Combo_UX_Merge_PATCH_V1_1_Visual_Closeout_Candidate.zip`。
- 范围：基于中国用户本地服务比较效率和支付决策的少量精准修复。
- 不改变：首页完整业务结构、双入口、推荐三卡与用户状态；S01 筛选顺序与服务标签池；S02/组合推荐；订单、优惠券、押金与管理费算法；数据母表、历史版本及路由。
- 价格规范遵循 `PRICE_SEMANTICS_DISPLAY_SPEC_V1.md`，保留「参考单价 / 整期总租金 / 月均约 / 预计下单一次支付」等现有词，不以“本土化”为名改写冻结价格语义。

## 2. 实施项（附可验证标准）

**CN-01 — S01 距离排序与推荐口径一致（P1）**
- 发现：旧 S01 「距离最近」实际按驾车耗时排序。示例「惠新西街店 1.8km/8分钟」排在「大山子店 1.6km/9分钟」之前。
- 修复：Browse 和显式 distance 排序均按 `routeFor(id).km` 升序，分钟数只作为同距离的次级排序；与最近门店推荐锚点同步。
- 「推荐排序」仍依照原匹配规则，「低价优先」仍依据对应的参考单价或整期租金；驾车/骑行/步行分钟数只是卡片到店信息，**未修改路线时间计算**。

**CN-02 — S01 实景图片可访问性及降级（P1）**
- 为 5 个已存在图片映射的门店补充真实 `<img>` 节点与 `loading=lazy`、中文 alt；维持原来的 CSS 背景图、既有仓体配色和图片路径，不替换门店事实来源。
- 未有图片映射的门店继续保持中性占位，不强行套用其他门店照片。
- 显示「仓储环境」，不将品牌环境素材直接断言为该具体门店核验照片。真实门店与素材身份需在生产阶段核对。
- 旧离线截图由于 `about:blank` 的相对资源限制显示空图片，不能据此断言原始相对文件资源缺失；本轮审计截图把仓储素材转为 data URI 以单独验证图片和布局，**不能等同于真实 HTTP 或微信端图像加载成功**。

**CN-03 — H01 门店环境替代文案（P2）**
- 保留首页第 1 卡既有真实仓储环境 CSS 背景图和完整首页模块顺序，只将隐藏的 `img` 替代文本「门店环境示意」改为「仓储环境展示」。

**CN-04 — U01 已选租期对比与费用可见性（P1）**
- 快捷租期「当前选中」增加清晰边框与背景区别，维持 44px 以上触控范围、七档及 1–60 个月自定义租期、全部折扣算法。
- 观察到全局 44px 帮助浮窗在 375 宽手机上与「预计首次应付」金额重叠；仅当实际几何发生重叠时临时隐藏悬浮入口。离开遮挡后恢复；底部「需要帮助」按钮始终可用。不删除全局帮助功能。
