## 本轮冻结范围

- 仅为内部演示准备界面。仓型内部净尺寸、门洞实测数据和典型大件包装/拆装尺寸暂缓，留待后续开发阶段。

- 不做多仓下单、押金/管理费规则重定、事实尺寸数据补齐或交易链改造。

## P0/P1 修复

1. **S02 组合卡文案与密度**：移除重复的“组合总容量达标，不代表物品可以实际放入……”整段警示、移除每间仓“（待核对）”以及没有分仓内容时的占位文本。摘要仅保留“组合容量可选 · 尺寸待核对”一处简洁说明；具体物品分仓建议有内容时才出现；保留“咨询此组合”以及附近门店兜底，不改变物理适配数据和策略。
2. **U01 租期与费用视觉修复**：修复全局 `body:has(#contractTotal)` 规则与 U01 局部价格组件混合导致的白字浅底、浅色金额和首次应付不可读。采用只作用于 `#termSection .term-price-combined .unified-price` 的视觉覆盖：暖白卡底、深灰费用标签、橙色整期总租金、橙底浅色的首次应付条，保留原租期控件及数据计算。
3. **验证边界**：原型 HTML 和全部链接 CSS 经 Chromium 离线排版验证。截图中的金额为排版测试夹具，非正式实时报价。受容器限制，原型 URL 的真实跨页点击及微信真机 E2E 仍未完成。

- `MINI_KOALA_PHYSICAL_FIT_V1` 的“可靠证据下拒绝不匹配；证据不足只允许容量候选”策略未修改。
- 门店标签随机池、S5/S01/S02 推荐和跳转、单仓支付及租后业务、库存/租金规则未改变。
