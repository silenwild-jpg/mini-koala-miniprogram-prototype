# V2.7.4.15 · 租期与推荐 / 门店仓位列表

## 本轮变更

- Estimator「租期与推荐」只从正式 `mini_koala_data.js` 的正价仓位中计算需求区间匹配结果，零价仓位不进入展示与价格计算。
- 每个推荐门店展示符合需求的容量区间；匹配数量按实际容量区间内仓位数显示为「匹配仓位 X 个」。
- 多个匹配仓位：按当前租期 × 月租金计算整期租金并取最低值，主价格为 `¥XX` + 弱化「起」，下方显示「合 XX 元/月」+ 弱化「起」。
- 单个匹配仓位：主价格显示 `¥XX/月`，下方显示「合 XX 元/月」。
- 没有匹配仓位时保留最近候选的连续流程，标记为「最接近当前需求」，不把候选误报为需求范围内匹配。
- 「门店仓位列表 · 完成」页将行政区作为弱化标签，门店名称作为主标题；删除详细地址展示与地址绑定，保留导航入口。

## 未改变

- 未改冻结 DOM 结构、模块顺序、中文主链文案、门店/仓位跳转和需求继承逻辑。
- 事实仍只来自生成数据源；没有在页面脚本中复制门店价格或仓位事实。
- 容量继续使用 m³；面积与尺寸沿用既定 2.5m 高度模拟规则。

## 验证

- 全量静态/运行时 QA：20 项通过。
- 静态包完整性：45 个 HTML、28 个内联脚本、422 个本地引用通过。
- 新增 `qa/test_v27415_recommendation_pricing.js`，覆盖正价过滤、匹配区间、最低整期租金、单/多匹配价格结构、行政区标签及地址删除。

本轮未进行真实微信环境、真实支付、真实地图服务或真机视觉验收；以上结论为本地静态与运行时原型检查结果。
