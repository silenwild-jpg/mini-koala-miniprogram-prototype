基线：Phase 3B Batch A+B Controlled PATCH V1。仅修改 U01 运行时 HTML；不修改 S01/S02、共享价格和库存数据、Q01/O01/O02。U01 的更新仅对候选版本有效；发布状态 HOLD。

## 已实施
1. 在容量标题和租期费用之间添加基于已确认需求的适用性摘要：符合范围、低于容量下限、超过“不超过”上限、更宽裕或无有效需求。特价标签不掩盖不匹配提示。
2. 保留整期租金主视觉及月均、押金、管理费、一次应付原有公式；将库存弱化并置于费用明细之后。U01 不显示由演示数据产生的实时查看人数与倒计时，也不启动其倒计时。
3. 未取得 actualUnitId 时，U01 显示“方案标识”，同时解释实际物理仓号尚未分配；已携带实际仓号才显示“已分配仓号”。保留数据源与订单 URL 参数，避免中断链路。
4. 当容量档位的明确库存为0且尚未分配实际仓号时，显示已售出并禁用继续租用、保存报价入口；库存数量未知时显示待确认，不伪称只剩1个。
5. 无明确租期参数且上下文中没有已确认租期时，不显示有效总租金，仅引导选租期。保留底部“需要帮助 / 继续租用”双按钮。
