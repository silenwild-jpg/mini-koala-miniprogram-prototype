# 门店仓位数据接入变更说明

## 交付范围

本次以《迷你考拉仓_门店仓位预填数据_V2_清洗版.xlsx》的正式母表结果为唯一门店、容量、可租数量和价格事实源，接入当前 V2.7.4.11 小程序母版。

- 源门店：145 家；前端可展示门店：126 家
- 源门店×容量档位：1,037 条；前端可展示档位：766 条
- 源可租数量：1,579；前端可展示数量：1,297
- 生成源文件：`data/mini_koala_data.js`
- 配套文件：`data/store_master.json`、`data/size_options.json`、`data/data_validation.json`

## 口径约束

- 产品口径确认 `size_unit=m³`，容量事实统一按 m³ 展示。
- ㎡按 `m³ ÷ 2.5m` 换算；长、宽按等边地面面积推导，高度统一为 2.5m。页面不标注“模拟”，生成数据仍保留估算状态，待真实长宽高补充后替换。
- `has_zero_price=true` 或 `display_price_min<=0` 的容量档位不进入前端展示数据；仅保留在源数据审计口径中。
- `price_min_raw` 仍保留在生成数据中，用于审计原始最低价与展示价的差异。
- 旧演示门店 ID 只保留为兼容别名，别名解析到生成数据中的正式门店，不再作为事实源。

## 接入页面

已加载 `../data/mini_koala_data.js` 并接入以下页面：

- Estimator：候选门店和匹配仓位改读生成档位与正价。
- S01：门店列表、容量范围、可租数量、匹配档位和起租价改读生成数据。
- S02：门店库存摘要、仓型档位、价格带和跳转参数改读当前门店生成数据。
- U01：仓位详情改读当前门店档位，展示 m³、换算㎡与推导长宽高。
- H01：首页门店事实卡和价格参考改读生成数据。

除“模型使用建议”聊天明确授权的 C-State P1 + D-Page Cleanup 项外，本次未改变冻结 DOM、页面结构、模块顺序、中文文案主链和交互逻辑。授权清理项包括：M01 正常在租标题与推荐卡视觉降级、S01/S02 图片占位中性化、S02 HIGHVALUE 说明与行动层级收敛；其余只替换数据读取、事实渲染和兼容映射。

## 静态回归

已通过：

- 源数据与前端展示数据计数、可租数量合计、`size_unit=m³` 约束。
- ㎡、长宽高换算和统一 2.5m 假设检查。
- 零价容量档位完全不进入前端数据检查。
- 五个接入页面均加载生成数据源。
- 五个页面内联脚本语法检查。
- SSOT、租期选择器、Sales Share Mode 等既有静态检查。
- M01 ACTIVE 标题/推荐卡优先级、S01/S02 图片占位词、S02 HIGHVALUE 动态仓位与行动层级专项检查。

未包含真实微信设备、线上地图/价格服务和生产交易接口验证；本包仍是低保真/VI-ready 母版。
