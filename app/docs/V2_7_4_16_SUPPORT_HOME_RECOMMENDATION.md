# V2.7.4.16 · 全局客服 / 首页门店推荐 / 推荐页层级

## 本轮变更

- 所有 HTML 页面统一保留右下角电话与在线客服浮窗：电话 `4000358805`；在线客服优先调用 `wx.openCustomerServiceChat`，通过 `window.MINI_KOALA_WECHAT_SERVICE` 或 `window.__MINI_KOALA_WECHAT_SERVICE__` 注入 `corpId` 与 `url`，未配置时保留可验证原型兜底弹层。
- 数据适配层新增单仓展示号规则：源表的多仓号事实不改，`getLegacyUnits()` 对外展示时保留第一个仓号，避免页面同时展示多个仓号。
- Estimator「租期与推荐」：删除「1–60个月任意整数月」；距离文案缩短为「约XX公里 · 驾车约X分钟」；行政区标签与门店名称同列左侧；「匹配仓位 X个」移动到地址下方并强化显示。
- S01 附近门店价格改用全局橙色价格 Token。
- 首页新用户默认演示为已获取当前位置状态；首页三张门店卡片从正式数据源选择北京、可租、容量可展示的门店，并按正价每立方米月租递减排序。

## 数据与交互边界

- 门店、仓位与价格事实仍来自生成数据源，未在页面脚本复制事实值。
- 首页动态门店使用正式 `mini_koala_data.js` 的门店 ID；路线缺少正式快照时仅使用确定性的原型路线兜底。
- 微信客服原生调用需要宿主环境注入微信客服配置；浏览器静态预览无法真正打开微信会话。
