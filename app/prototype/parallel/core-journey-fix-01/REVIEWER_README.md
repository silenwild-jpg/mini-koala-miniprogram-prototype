复查顺序：

1. 打开评审页，再进入附近门店。默认前两店展开，每店最多两个单仓预览；任一店可独立展开/收起。
2. 在页面顶部“内部演示设置”选择“正常匹配”；通过沿用的手机号验证交互后，前两店四条预览分别出现 N/P/L/PL。这是受控本地数据，不会发短信。
3. 第2店 A04 在6个月下为 ¥2,600；比较 S01、S02 和 O01。同一核心核价函数负责这三处金额。
4. 不选租期点击立即下单，应停留并提示“请选择租期”；关闭验证应保留需求；不足容量的其他可租仓位必须先修改需求。
5. 选择无匹配和售罄场景，核对其他可租容量、其他门店与顾问入口。

不应恢复：旧稿门店级剩余/匹配数量、容量范围、默认租期、随机促销标签、凭空的客户物品或箱数。促销仅在明确活动、目录版本、价格、有效期、租期及授权条件全部满足时展示。仅两个显式且完整的同容量库存组允许数量提示。
