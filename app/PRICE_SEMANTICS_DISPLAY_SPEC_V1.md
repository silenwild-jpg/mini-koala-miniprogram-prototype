# Price Semantics & Display Spec V1.1

状态：**FROZEN AFTER FINAL CLOSEOUT**  
基线：`V1.5.1 — S01 / S02 Estimator Return Context PATCH`

## 1. 全局价格阶梯

1. **未选租期**：只展示参考价格，不作为成交价格。
2. **已选租期**：`整期总租金`成为唯一主租金。
3. **月度数字**：由整期总租金折算，统一命名为`月均约`。
4. **进入具体仓位后**：补充押金、管理费。
5. **确认订单前**：明确`预计下单一次支付`及其组成。

## 2. 冻结文案

- 首页推荐模块级辅助说明：**实际价格以具体仓位和租期为准**。
- 已存在有效租期时，原“参考月租”统一改为：**当前租期参考**。
- 尚未选择租期时，不得暗示存在“当前租期”；S02 Browse 使用：**参考价格**。
- 参考门店比较价格：**参考单价**。
- 已选租期主价格：**整期总租金**。
- 月度辅助价格：**月均约**。
- U01 / Q01 确认订单前应付：**预计下单一次支付**。

## 3. 算法口径

- 租期折扣沿用现有 SSOT：1–3月 7.5折；4–6月 7折；7–12月 6.5折；13–36月 6折；37–60月 5.5折。
- `total_rent` 为正式整期租金，沿用当前“整期计算后取整到十元”规则。
- `monthly_average = round(total_rent / term_months)`，因此只允许展示为“月均约”，不作为权威应收月租。
- 未选租期的首页 / S01 Browse 可继续使用 65% 发现阶段统一参考口径，但用户端不得暴露“统一65折/发现价”等内部术语。
- Estimator 一旦已有租期，附近同类空间参考必须使用该租期对应折扣，禁止继续使用折前价或固定 65%。

## 4. 页面规则

| 页面 | 未选租期 | 已选租期 / 具体方案 |
|---|---|---|
| H01 | 参考单价 + 模块说明 | — |
| Estimator | 不生成正式方案价 | 整期总租金 + 月均约；附近参考按当前租期 |
| S01 Browse | 参考单价 | — |
| S01 Estimated | — | 整期总租金 + 月均约 + 折扣 |
| S02 Browse | 参考价格 + 选择租期后重新计算 | — |
| S02 Matched | — | 整期总租金 + 月均约 + 折扣 |
| U01 | — | 整期总租金 + 月均约 + 押金 + 管理费 + 预计下单一次支付 |
| Q01 | — | 复述同一 Price Snapshot；费用与方案保存说明分离 |
| O01 | — | 继续使用整期总租金 + 月均约；本次应付为交易主金额 |

## 5. Price Snapshot SSOT

从 U01 形成 `mini_storage_price_snapshot_current`，至少包含：

- `store_id`
- `unit_id`
- `size_option_id`
- `term_months`
- `discount_rate`
- `base_monthly_price`
- `total_rent`
- `monthly_average`
- `deposit`
- `management_fee`
- `upfront_payable`
- `pricing_model_version`
- `pricing_timestamp`

Q01 / O01 在 store / size option / term 匹配时必须优先读取该快照，不得用 URL 参数重新解释价格。

## 6. 其他语义

- 多仓位最低价写作 `¥X起`，禁止 `¥X/起`。
- “省 ¥X”必须说明比较对象；当前推荐链使用“比最近门店整期约省 ¥X”。
- 考拉E存明确为“按体积套餐计费”，不得与实体仓位假设为同一计价模型。
- Q01 的“48小时找回”属于方案保存说明，不得放在费用明细。
