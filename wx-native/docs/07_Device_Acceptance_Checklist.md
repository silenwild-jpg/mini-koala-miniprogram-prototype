# 真机验收清单（设计侧收尾 T7，2026-11-18）

设计稿的全部证据都是 Chromium 375 / 390 宽的截图，**没有一项在微信里验证过**。这份清单列的是必须在真机上看的点。每一批开发结束走一遍对应部分，结果填在「结果」栏。

建议机型：一台带刘海或灵动岛的 iPhone、一台小屏 iPhone（375 宽）、一台主流安卓全面屏、一台低端安卓。微信版本和基础库版本每次记录。

标 ★ 的是可能导致设计要改的项（平台做不了就得解冻，由张坤裁）。
