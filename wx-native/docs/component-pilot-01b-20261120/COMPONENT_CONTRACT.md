# 01B组件约定 v1｜本批实施契约

来源：[01A审计](../visual-audit-01a-20261120/AUDIT.md)、用户关于卡片/页面信息密度的确认，以及现行原生规则。本批最终候选 `f125158d64371e84877d5e445f70f528c39ac1e4`，运行时树 `08c8e86df7098bd1ef85fb6e9278d1ca7836dce1`。工程约定已落实到列示源码；[原生验收](G_VIS.md)仅限已测范围，不是全站人工签收。

## 信息层级

- 选仓卡直接保留体积、单仓/组合事实、各仓编号、容量不足、价格口径、可用状态和行动；不以图标或弹窗替代风险信息。
- 门店标题区最多两个标签位，包含推荐标记；这是门店标题区的预算，不是裁剪整张卡所有风险提示的通用上限。
- 泛化用途与全店库存数量不恢复主显；详情放到已有门店页、页签、组合展开和费用入口，避免新增解释卡及嵌套弹窗。
- 增强正常说明的可读性时保持字号和层级，不通过加大/加粗所有信息增加密度。

## 本批落实的约定

| 范围 | 规则 | 实现与边界 |
|---|---|---|
| 正常说明文字 | 非禁用的登录用途、看仓声明/回执、费用说明、报价单位、存取时段、交易确认提示使用可读的次级前景 | 局部覆盖为`--mk-color-ink-secondary`；白底声明颜色对比5.56:1。全局tertiary、禁用与占位规则未改，不把本批局部修复写成全部灰字已解决 |
| 通用弹层关闭 | 图标大小保持原值，扩大实际命中区域 | `.sh-close`为96rpx并设48px最小宽高，flex不收缩；负边距保持原头部占位节奏。375/390下声明值约48/49.92逻辑像素；实际大小与边缘点击是否可用必须另测 |
| 门店地址摘要 | 摘要仍可两行截断，但完整内容必须在产品内可查看 | 点原地址摘要复用`onSeeRoute`，进入原交通路线页签并滚到页签；不新增常驻按钮/卡片/弹窗；可访问名称包含完整地址 |
| 完整地址与复制 | 在已有路线信息区显示不截断的完整地址，保留原路线备注和复制入口 | `.sd-fulladdr`允许换行；复制仍取源门店地址，不复制省略后的摘要，不改变需求、所选仓位或门店ID |

## 本批没有替代的业务规则

≥30m³继续自助；80%容量接近且明确差额；S5修改回CAP/ITEMS；正式报价/下单登录门禁；特价及租期折扣使用统一报价；看仓独立销售线索且不锁仓；U01不恢复。这些规则仍由现行服务与测试约束。

## 组件传播与回归

共享弹层通过登录、租期、需求、看仓等递归影响28页，具体调用方见[source-audit/COMPONENT_IMPACT.csv](source-audit/COMPONENT_IMPACT.csv)。初候选完成35页双尺寸默认态检查，最终候选完成24张关键图确认。关闭区375/390实测48×48、49×49逻辑像素；边缘点击因原生坐标接口不支持仍未验证。默认态截图不等于该页全部状态已验证。

地址摘要使用外层触摸容器与内层两行截断文字，避免最小触摸高度使第三行残影泄露；最终双尺寸已确认残影消失。正常文字计算色为`rgb(95, 107, 101)`。

新增4项行为回归覆盖：S5/S02的10对8近似、10对5无匹配、30对16+15组合、长地址进入路线并复制全文且需求不变。完整164项Node回归、模拟调用和模板编译独立存证。

原生10/8、10/5、31组合为隔离渲染fixture：由真实视图模型生成或调用页面paint，只更改页面副本，不是生产库存、不执行fixture下单。真实流程与渲染证据分别记录。
