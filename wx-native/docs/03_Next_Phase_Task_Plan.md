# 冻结后的任务安排：从设计稿到微信小程序体验版（W27，2026-11-18）

前提：视觉与结构冻结在 W27（D-193）。目标：一个能在微信里扫码体验的版本。
说明：我不知道开发由谁做、有几个人，所以下面只排顺序和依赖，不给工期。涉及微信平台规则的地方是按我掌握的情况写的，没有逐条核对官方文档，开工前请以官方文档为准。

## 0. 开工前需要你先定的 4 件事

| # | 事项 | 我的建议 | 为什么要先定 |
|---|---|---|---|
| 1 | 技术路线：微信原生 / 跨端框架 / 用 web-view 套现有网页 | 微信原生 | 体验版最需要验证的是隐私弹层、手机号、定位、订阅消息、支付，这些在 web-view 里验证不了或要绕路；跨端框架只有在确定还要做其他端时才值得 |
| 2 | 体验版的范围 | 先做找仓和交易主路径（§2 第 1、2 批），其余分批 | 34 页一次做完，真机问题会到最后才暴露 |
| 3 | 后端：体验版用本地演示数据，还是接真实接口 | 先用演示数据，接口层留好 | 仓库 `runtime/` 里的规则和演示数据是纯逻辑脚本，可以先搬进小程序；能否原样运行我没有验证 |
| 4 | 小程序账号：主体、AppID、服务类目是否已就绪 | 需要你确认 | 手机号快速验证、支付、定位接口都要求已认证的企业主体，并各自要在后台开通 |

## 2. 体验版开发分批（开发侧）

| 批次 | 内容 | 依赖 | 完成标志 |
|---|---|---|---|
| 第 0 批 准备 | 项目骨架、设计令牌转样式、通用组件（顶栏、底栏、卡片、弹层、按钮、表单、状态页）、演示数据层 | T1、T5；账号就绪 | 一个空壳能在真机打开，底部导航可切换 |
| 第 1 批 找仓 | 首页、用仓位置、填容量、按物品估算、仓位推荐、门店列表、门店详情（含到店指引） | T2 | 不登录能从首页走到看见仓位；隐私与定位合并弹层真机通过 |
| 第 2 批 交易 | 登录（手机号）、确认订单、实名认证、签署、支付（先用模拟支付）、订单详情、订单列表、快捷下单 | 手机号组件已开通 | 能从仓位走到「订单已支付」；3 小时报价有效期、满额减、已省金额算对 |
| 第 3 批 租后 | 续租、退仓、押金、发票、电子合同、入仓指引、消息 | 订阅消息模板已申请 | 续租与退仓两条路径走通；提前退仓预计结算与设计稿一致 |
| 第 4 批 其余 | 预约用仓、企业用仓与认证、「我的」各子页、优惠与权益、收藏、E存、协议页 | 无 | 全部页面可达 |
| 第 5 批 接入 | 真实接口、微信支付、地图、电子签、开锁 | 后端与外部接入就绪 | 逐项替换演示数据 |

每一批结束做一次真机走查，问题回到设计侧的只应是缺陷和业务口径，不动视觉和结构。

## 3. 真机必须确认的点（现在都没有验证过）

1. 首页隐私与定位合并成一个弹层：依赖基础库版本，旧版本怎么降级。
2. 手机号快速验证：用户拒绝后走短信验证；取号按次收费，门槛前移后调用量会上升，提审时要说明用途。
3. 定位接口：需要在后台申请，能否获批与服务类目有关。
4. 订阅消息：授权框只能在点按回调里弹；订阅框和支付在同一次点按里先后出现是否可行；一次性订阅隔数月再下发是否受限。
5. 支付调起、取消、失败返回后的页面状态。
6. 弹层里输入框被键盘顶起、长页面滚动时底栏和顶栏的表现。
7. 状态栏、胶囊按钮与自定义顶栏的避让；不同机型的底部安全区。
8. 主包体积：图片较多，可能需要分包或放线上。

## 4. 并行推进的四条线（不挡体验版，但挡上线）

| 线 | 要拿到的东西 | 找谁 |
|---|---|---|
| 财务 | 过去 6–12 个月订单明细与各仓型出租率；折扣中间三档、满额减三档定档 | 财务 |
| 业务 | 实际仓位长宽高；增值保障与 E存价格；发票是否含押金与开票时限；券有效期；逾期补缴方式；协议版本号与生效日期；外地用户是否受理 | 运营、门店 |
| 法务 | 隐私保护指引与隐私政策正文；注销条件与撤回授权后果；约 50 条界面短句；E存部分召回两条款矛盾 | 法务 |
| 外部接入 | 地图服务、开锁设备、第三方电子签、订阅消息模板 | 技术、采购 |

隐私保护指引要在小程序后台填写后，相关接口才可用，所以法务这一项最好排在第 1 批真机走查之前。

## 5. 冻结期间设计稿的规则

- **可以改**：缺陷（显示错误、文字错误、与裁定不一致）；业务或法务给出的口径替换占位；财务定档后改数字。
- **不改**：布局、组件、颜色、字号、页面结构、信息层级、流程步骤。
- **要解冻才能做的**：真机上发现原设计在微信里做不了的地方。遇到时单独列出，由你裁。
- 每次改动仍然登记台账、跑全站回归，并更新冻结清单。

## 6. 暂不启动的

- 定价第二、三阶段（分门店折扣、仓型价格阶梯、自动调价）：等第一阶段上线后有数据。
- 订金产品、企业经办人实名与授权书、非身份证证件：随电子签接入一起做。
- 把浏览器设计稿做成可点击：见成熟度评审 §5。
- 10 月的旧线（Release Gate H01-007 仍为 HOLD；S4–S5 与母版遗留）：它们针对的是旧视觉的 Web 原型。体验版走微信原生的话，建议你明确关闭这条线，否则会一直挂着。
