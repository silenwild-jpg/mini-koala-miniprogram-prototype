# 规则配置表（设计侧收尾 T4，2026-11-18）

把会变的数字从页面里拿出来，做成一张配置。财务、业务定档后只改这张表，不改页面。机器可读版是 `rules_config.json`（58 个参数）。

「性质」一列的意思：
- **已裁**：张坤给的数或明确裁定。
- **示例**：我给的结构示例，等财务按成交数据定。
- **自定**：设计侧定的初值，张坤已裁定保留（D-191），业务可以调。
- **待数据**：等业务提供实测或实际数据。
- **协议**：来自使用协议条款。

## 8. 提前退仓

按协议：按实际使用时间收费（不足 1 个月按 1 个月）+ 违约金 + 预付优惠按实际使用周期重算。界面只给一个带「约」的预计数，不写比例。

预计数的三处算法是设计侧自定，正式结算以后端为准，要业务确认：
1. 剩余月数 = 租期 − 已用月数。
2. 优惠重算按已用月数对应的公开折扣档补差。
3. 剩余合同金额按折后月租算。
