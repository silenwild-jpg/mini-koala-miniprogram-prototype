### 隐私保护指引：要声明的信息类型（草稿，待法务确认）
用途说明会显示在微信的授权弹窗里，是给用户看的话。下面是我按现有设计列的草稿，**措辞没有经过法务**，隐私政策正文也还没有。

| 信息类型 | 哪里用到 | 用途说明草稿 |
|---|---|---|
| 位置信息 | 首页、门店列表、用仓位置 | 用于为您查找附近的门店并显示距离 |
| 手机号 | 登录、预约用仓、企业用仓的联系电话 | 用于登录账号，并在预约和订单服务中与您联系 |
| 选中的照片或视频、摄像头 | 企业认证上传营业执照 | 用于上传企业认证所需的证照 |
| 身份证号码、姓名（如指引里有此项或需自定义补充） | 下单时实名认证 | 用于签署使用协议前的实名认证 |
| 订单信息、发票信息（如需自定义补充） | 订单、开票 | 用于提供仓储服务与开具发票 |

- 后台的信息类型是从固定列表里勾选的，列表里具体有哪些项我没有看到；上表后两行可能要用「自定义补充」。
- 设计稿没有用到的不要勾（如通讯录、麦克风、蓝牙、微信运动）。开锁接入后如果走蓝牙，届时再补。

### 定位接口的用途说明（草稿）
> 迷你考拉仓为用户提供线下自助仓储门店的查找与到店服务。小程序在首页和门店列表使用用户当前位置，按距离排序展示附近门店、显示到店距离，并在用户到店时提供门店导航。位置仅在用户使用找仓功能时获取，不做持续定位。

申请时一般还要附使用场景的截图或录屏，可以用设计稿的首页、门店列表、用仓位置面板三张图。

### 订阅消息模板：四个节点各需要的字段
模板只能从公共模板库里选现成的，下面是每个节点希望带的内容，按这个去库里找最接近的。

| 节点 | 触发 | 希望带的字段 |
|---|---|---|
| 预约受理 | 提交「预约用仓」后，顾问受理时 | 预约门店或区域、预约时间、受理状态、联系电话 |
| 续租报价 | 门店给出续租报价时 | 门店、仓位、续租租期、报价金额、有效期至 |
| 验仓结果提醒 | 退仓验仓完成时 | 门店、仓位、验仓结果、备注 |
| 租期到期提醒 | 到期前若干天 | 门店、仓位、到期日期、温馨提示 |

四个模板的标题不能相同：同一次授权里标题相同的只保留一个。提前多少天发到期提醒，现在没有业务口径。
