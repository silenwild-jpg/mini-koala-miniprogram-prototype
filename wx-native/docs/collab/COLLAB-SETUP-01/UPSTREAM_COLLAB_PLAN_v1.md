## 2. 仓库约定

- 工作线只有一条：`codex/*` 分支，基于 `feat/wx-native-rule-baseline-20261120`。
- 评审分支：`claude/review-<SHA前7位>`，从被评审的提交拉出，只新增 `wx-native/review/<SHA前7位>/` 目录。不合并，只供阅读。
- Codex 每个任务包开一个 Draft PR；我在 PR 下留评论并指向评审分支。
- 规则顺序不变：张坤最新指令 ＞ 11-20 六项修订 ＞ 40 条清单 ＞ 冻结稿（W27）。

## 3. 每一轮怎么转

1. Codex 推送，在群里回报：分支、完整 SHA、PR 号、证据目录。
2. 张坤在群里发「评审 <SHA>」。**我没有后台进程，不会自己发现新提交，需要这句话触发。**
3. 我当轮完成：拉取、复跑四项门禁、看图、出 `REVIEW_<SHA>.md` 和 `review_issues.csv`，推评审分支，群里给结论和「需裁」清单。
4. Codex 逐条处置（已修 / 拒绝及理由 / 需裁 / 延后），进入下一轮；只重截受影响页面。
5. 张坤只处理「需裁」项和真机项。
