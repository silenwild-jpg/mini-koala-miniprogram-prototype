## 3. 两档幅度的区别（第 2 步要你选的东西）

- **A 档 重排不重构**：模块还是这些模块，只调顺序、分组、留白和字号权重。改动面小，现有 243 态基本都还成立，风险低。
- **B 档 版式重构**：允许改模块结构（合并、拆分、换形态），首屏内容重新取舍。效果更明显，但每页的状态要重新过一遍，测试与预览图要重做。

可以按页型混用，例如交易与租后用 A 档（状态多、出错代价高），首页与找仓用 B 档。
