# 门店卡信息写法基准（IMPL-01，find 域定，全站对齐）

实现在 `components/mk-store-card`，数据在 `services/finder.js` 的 `storeCard` / `buildMatch`。首页推荐、收藏等自己画卡的地方照此对齐。

1. 骨架：左图（160×144rpx，圆角 `--mk-radius-thumb`），右侧三行：店名 → 位置行 → 标签行；发丝线（卡内唯一一条）下面是规格与价格。
2. 位置行：`距离 · 区名 · 商圈`，例「1.2km · 朝阳区 · 安贞」。距离用 `mk-num`、主色加重；区名与商圈次要色跟在后面，同一行。没有商圈写小区名；没有定位时只写「朝阳区 · 安贞」。不带省市与门牌。
3. 字段：`card.kmText`（距离）、`card.placeText`（区名 · 商圈，不含距离）、`card.locText`（整行，只有一个文本位时用）。分隔符统一 ` · `。
4. 标签行：统一用 `mk-tag`，一行、最多两个、不换行。优惠类（特价仓、满 6 个月免费运输）用 `mk-tag--promo`，库存紧张用 `mk-tag--warn`，服务类（近地铁、电梯直达、停车便利等）用默认灰底。距离、价格不进标签。
5. 价格：不进任何串，在发丝线下单列，用 `mk-price`。无需求：左「可租容量 a–b m³」，右「¥X/m³/月起」。有需求大卡：仓位行「A003 · 3.5m³」，下面左价格（月价 + 折扣标签，次行「整期 ¥X · 6个月」）、右按钮。有需求紧凑卡：左「匹配 4m³」，右月价、下面小字「整期 ¥X」。
6. 组合方案：「N 间组合」成标签，后跟「A003 + A005 · 11.5m³」；容量接近的差额「小 0.5m³」成 `mk-tag--promo` 标签。
7. 角标：「距离最近」用 `mk-corner`，「区域低价」加 `mk-corner--price`，压在门店图左上角（父元素 `position: relative`）；没有图时退回成标签行里的 `mk-tag--brand`。字段 `card.rankTag`（文字）、`card.rankKind`（`near` / `price`）。
8. 角标规则：只用 `finder.rank` 的结果。第一位且按距离排出的标「距离最近」；第二位且确实是半径内更便宜的那家标「区域低价」。手动排序、被置顶或分组挪走的、运营位，都不标。
9. 操作：整卡点进门店；大卡的按钮是唯一的行内操作。不在说明串里放「查看门店」这类文字入口。
10. 动效：卡片 `mk-press`；列表前几张传 `enter="{{index}}"` 错峰渐显；价格变化传 `bump`。
