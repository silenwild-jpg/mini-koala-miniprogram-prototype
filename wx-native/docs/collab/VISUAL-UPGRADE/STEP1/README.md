**跨页的共性问题**（多个域各自独立指出）：

1. 橙色一色多义：促销（特价仓、折扣）和警示（仅剩 N 个、等待中）是同一组色值。
2. 订单卡太大：约 300px，在确认订单、租后四页、运输页都把该页真正要做的事挤到后面。
3. 同一金额或同一动作在一屏里出现两三次：确认订单、续租、快速下单、订单详情、首页任务卡。
4. 金额写法至少五种，状态头、失败说明的位置、底部栏主次在租后七页之间不一致。
5. 留资五页的表单规则不统一：必填标记、电话、日期、选项各有两三种写法；提交后的结果态有三套。
6. 并列图标黑绿混用；票券、日历图标一图多义。
7. 素材三种画风：门店实拍、扁平小插画、3D 物品图；品牌标识是色块占位。

**用色比例**：现状图里绿色像素约 2%、白与近白约 85%；品牌规范写的是绿 60%、白 30%、橙 10%。这是方向稿最需要定的一件事。品牌色按「暂定近似值」处理，这一步不动主绿。

## 3. 门店图（GitHub 检索结果）

- 仓库里能用的门店图有两批，都是迷你考拉仓的仓内实拍，清单文件都注明**没有核实是哪家门店拍的**：
  - 12 家演示门店各 2 张（小程序已在用），最大 1152×720；原图 3120×3120 不在仓库里。
  - `app/assets/real_store_demo/v1/` 5 组 19 张（900×1200 至 1600×1200）和 1 张 2048×1365 的大图；其中约 9 张小程序还没用。
