基线：`a3c3b53`（ACCOUNT-LEAD-01）。本批没有在微信开发者工具里编译或截图，校准留到后续批量执行。
依据：冻结稿 `design-frozen/pages/h01.html`、`design-system/components.css`（.card / .hero / .task / .rcard / .scene / .ent / .brand）和 `assets/nav`；决策 D-11（场景图沿用现有切图）、D-12（首图用 SIM_BJ03 门店图）、D-30（企业横幅白卡）。

## 做了什么

### 1. 卡片

- 全站 `.mk-card`：由只有底边一条线改为四周 1px 描边。冻结稿的卡片是 `border:1px`，运行时之前只画了底线，在浅灰底上卡片边界不清楚。用 `box-shadow: 0 0 0 1px` 画，不改盒子宽度，各页版式不动。
- 新增 `.mk-card--float`（冻结稿 `.card.float`）：绿色调柔和投影、不描边。只用在首页双入口。测试会拦其它页面使用。

### 2. 首页（对齐冻结稿 H01）

| 区块 | 之前 | 现在 |
|---|---|---|
| 首屏 | 灰底，只有标语 | 门店图铺到页面最上方（含状态栏、顶栏下面），下方 78% 渐隐到白；标语 28px 压在渐隐区 |
| 顶栏 | 白底 | 在图上透明，滚动超过 24px 变白底；加载、失败、断网时不出图，顶栏保持白底 |
| 双入口 | 白卡，纯文字 | 悬浮卡，右下角 48px 插画（地图 / 计算器） |
| 推荐卡 | 图片内缩在卡片里 | 图片通栏 16:10，文字区在下方 |
| 常见存储场景 | 六个文字块 | 三列图块：正方形下沉底 + 透明底切图 + 场景名 |
| 企业存储 | 文字上下排 | 左侧浅绿图标块，右侧链接，一行 |
| 品牌区 | 白卡，绿色数字居中 | 无卡片，品牌名加绿色方标，数字深色左对齐，上下发丝线 |
| 页面底色 | 浅灰 | 白 |

- 首图高度在 `onLoad` 里算：屏高 25%，夹在 190–230px；状态栏高的机型按「顶栏 + 标语区 96px」撑高。参数在 `core/config-find.js` 的 `hero`。
- `app.js` 的 `layout` 加了 `windowHeight`（取 `screenHeight`）。
- 场景图文件名在 `i18n/find.js` 的 `sceneImages`，与 `sceneList` 按位置对应。

### 3. 底部导航图标

- 现有 8 张 PNG 与冻结稿 `assets/nav` 的 SVG 逐像素一致（81×81），图形没有问题。
- 颜色与文字不一致：图标选中色 #176949、未选中 #78847E，而 `app.json` 里文字是 #0B7A48 / #5F6B65。本批统一成令牌色。
- 来源放进 `design-src/tabbar/`，由 `tools/gen_tabbar.py` 生成并写哈希清单；`static_check.py` 核对 PNG 没被手改、`app.json` 的文字颜色等于令牌。重新生成需要 playwright，核对不需要。

### 4. 工具

- `static_check.py`：加导航图标核对；首页配图必须有人引用、引用的必须存在。
- `preview_render.js`：`<image mode>` 的 aspectFill / aspectFit 现在按 cover / contain 渲染（之前一律拉伸）。
- `gen_icons.py` 重跑：新增 `building-brand.svg`（企业卡图标），图标文件 69 个。

## 要在开发者工具里确认的点（批量校准时一起看）

1. 首图：`position:absolute` 的图片是否铺到状态栏下面；顶栏 `sticky` 加透明底，滚动时切白底是否有闪动；下拉刷新时首图上方露出的底色。
2. 首图上状态栏文字（黑色）和胶囊按钮在照片上是否清楚。
3. 标语是否落在渐隐区内、不压到照片里的绿色墙面；375、390 和带灵动岛的机型各看一次。
4. 双入口：`.mk-card--float` 的投影是否被 `mk-gutter` 或页面裁掉；插画是否压到「查看门店 ›」。
5. 推荐卡：`overflow:hidden` 加圆角后图片上边两个角是否圆；横向滚动时描边左右是否被裁（轨道上下留了 2rpx）。
6. 场景图块：`calc` 里嵌套 `var()` 算出的高度是否等于宽度（应为正方形）；`:nth-child(3n)` 是否生效（每行三个）。
7. WebP 透明底切图在 `<image mode="aspectFit">` 里是否透明。
8. 底部导航：图标绿与文字绿是否一致；81px 图在 2 倍和 3 倍屏上的清晰度。
9. 全站卡片四周描边：与 `mk-notice` 左侧色条、卡片内通栏图片叠在一起时有没有重线。
