- **M-34 五格入口**：预约用仓、找仓进度、我的收藏、优惠与权益、消息五项齐全，跳转与登录拦截沿用原逻辑（`pages/mine/index.js:67-74`），消息未读徽标保留。「账务与企业」「更多服务」两组各四行没动。丢掉的是各行右侧副文案（已登记 PR-260），我认为其中「预约用仓」的语义损失是缺陷，见 D2-03。
- **M-35 / M-36 个人信息**：头部已删；「更换」「修改」并入各自字段行行尾，提示句成卡底小字。没有丢信息。
- **M-37 推荐有礼**：一张主卡，顺序是状态标签、标题与说明、邀请码、两个按钮，筹备说明在卡下。与裁定一致，未登录态完整。

- **没有发现**：P0 / P1 问题；占位符、undefined、NaN、原始枚举值露出；同一订单跨页金额或日期不一致（A003、A005、B002 在「我的仓位」、任务卡、批量开票三处能对上）。

## 4. 做得对、不需要改的

1. **五格常用入口**：五项齐全，只有消息带未读徽标，未登录时照常显示并按原逻辑拦登录。「我的」首屏比两张列表卡时短了一截，任务卡更突出。
2. **个人信息页**：删头部后直接进入字段。「更换」「修改」贴在各自手机号行尾，动作与对象的对应比原来卡底双按钮清楚，提示句降成小字。
3. **推荐有礼主卡**：顺序与裁定一致，筹备说明降到卡外小字。未登录时邀请码位写「登录后查看」、两个按钮禁用并给登录入口，状态完整。
4. **企业认证门槛的各处拦截**：批量开票拦截页、开票抬头「企业」项置灰加说明、「我的」页企业认证行右侧状态（审核中 / 已认证 / 未通过）三处口径一致，都给了去向。拦截页还提示「单笔订单开票不需要企业认证」。
5. **仓位编号标签**：「我的仓位」、任务卡、收藏、批量开票四处都是白底描边编号在前、容量在后，写法一致。
