## 4. 九段要求在本旅程的落实情况

落实了的（图与源码都能对上）：
- 首页推荐卡加角标；入口卡改浅灰底，不用浅绿；场景改圆形图标一行，右侧露半个图标表示可滑；品牌区有五城地标线条和三张资质图；底部红字配图提醒已删。
- 门店详情：存取时间进服务设施第一格；地址、距离、导航图标同一块；底栏为收藏 / 分享 / 预约看仓 + 在线问 / 打电话；页内不再有预约看仓和电话图标区块；仓号单独成标签并与容量同行；到店指引有可点的地图块；顶部图多图横滑、高度压到 320rpx；三个页签改同页分段。
- 容量页 AI 估算隐藏；快捷档改成刻度滑杆；尺寸示意上移。物品页 AI 入口与「直接填容量」已去掉，物品行换成实物图。
- 门店列表地址行改为「距离 · 区 · 商圈」，价格独立在右，两种卡骨架一致。

落实走样或没法确认的：
- 角标在部分需求下消失（A2-01）；「区域低价」读法有歧义（A2-04）。
- 服务设施与到店指引「全量补全」只做了一家店（A2-08）。
- 首页「找门店为第一视觉权重」需真机确认（见第 1 节）。

## 5. 做得对、不需要改的

1. 价格口径跨页一致：未登录只出「¥X/月起」+「查看报价」，登录后出「¥X/月 + 折扣标签 + 整期金额」；同一仓位在附近门店、仓位推荐、门店详情三页金额相同（B003：未登录 ¥292 起，登录 6 个月 ¥315、整期 ¥1,890）。
2. 仓号标签（描边小标签）+ 容量同行的写法在列表、推荐、详情、已租出仓位四处一致，组合方案每个仓号各一个标签。
3. 门店详情底栏与头部地址块完全照要求落实，页内没有残留重复入口。
4. 未定位、断网、全城无匹配、登录拦截这些状态都有内容和操作，没有发现占位符、undefined、NaN 或原始枚举值露出。
5. 首页随订单阶段收放（有在租订单时入口变弱、推荐不出；有需求时不出「估大小算价格」）与 M-04、M-05 裁定一致。
