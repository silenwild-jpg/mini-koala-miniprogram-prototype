## 2. 走查结论

| 步骤 | 结论 |
|---|---|
| 仓位 → 确认订单 | 能走通。未登录被 `auth.navigate` 拦在原页并打开登录层；直达受限页会被带回落点页 |
| 实名认证 | 能走通。未实名时底栏主按钮是「实名认证」，信息不一致有红字，可直接重试 |
| 协议勾选与签署 | 能走通。未勾选时主按钮禁用并提示「请先勾选确认」；签署弹层列出签署人、门店、仓位、租期、应付和协议链接 |
| 预计用仓日期 | 能走通。确认订单默认填明天，可选明天起 90 天内；月末起租时到期日算错，见 B-01 |
| 优惠券 | 普通仓能走通，金额正确。特价仓能选券但不生效且无说明，见 B-03 |
| 费用明细 | 图上 7 组数字逐行相加都等于合计，见 §4 第 1 点 |
| 支付 | 能走通。签署后自动开支付弹层，「暂不支付」留在待支付态，倒计时自下单起 3 小时 |
| 支付成功去向 | `redirectTo` 订单详情（带 `paid=1`），先显示「正在确认支付结果」，再显示「入仓准备 / 待起租」。没有明确的「支付成功」字样，见 B-15 |
| 支付失败 | 四项一致或只有价格变化时能走通，订单号和截止时间不变。优惠资格变化时走不下去，见 B-02 |
| 待支付超时 | 能走通。每秒检查，到点转「订单已超时」，底栏变「重新找仓」，页内列其他可租门店和「预约顾问」 |
| 下单时变价 | 能走通。弹层写明原因和前后四项金额，「确认新报价」后按新价重新报价再签，「查看其他方案」回门店详情 |
| 仓位被租走 | 有明确提示，下一步是卡片上的「更换」；底栏主按钮是禁用的，见 B-11 |
| 报价过期 | 能走通。横幅和底栏都能「刷新报价」，不触发登录；旧金额仍留在页面上，见 B-07 |
| 订单不存在 | 订单详情有空态和「返回订单」。确认订单页带不存在的订单号时文案不对，见 B-05 |
| 付款后补实名 | 能走通。订单详情主按钮「完成实名认证」→ 实名页，未通过可「重新提交资料」 |
| 快捷下单 | 能走通。缺项时底栏写「还需 X」并禁用主按钮；未登录选齐后主按钮「查看报价」打开登录层，登录后留在本页 |
