## 2. 走查结论

| 步骤 | 结论 |
|---|---|
| 首页 → 找附近门店 / 估大小算价格 | 能走通。双入口、推荐卡、六个场景、企业横幅、品牌区都有去向 |
| 填容量 → 查看仓位报价 | 能走通。提交后 `redirectTo` 仓位推荐，返回回到首页，不会回到表单 |
| 填容量 ↔ 按物品估算 | 能走通，互相可达，回退不叠页。物品页未选物品时主按钮禁用并写「请先选物品」 |
| 门店列表（无需求 / 有需求） | 能走通。无需求给估算入口，有需求给修改入口 |
| 仓位推荐 | 能走通。无需求进入会被带去填容量页；「修改」按来源回填容量或物品页 |
| 门店详情 | 能走通。匹配仓、比需求小的仓（按 X m³ 重新匹配）、已租出折叠都有 |
| 登录拦截 | 能走通。未登录点「查看报价」在当前页开登录层，登录后留在原页显示整期价；直达确认订单被带回仓位推荐并提示「请登录」 |
| 未登录不显示整期金额 | **符合**。未登录时列表、推荐、详情三处的数据里都没有 `rentTotal`、没有「整期」、没有「每月多 ¥X」（运行核对 + 图 04 / 08 / rv35 / rv32 / rv34）；顾问卡未登录只按容量判定，不间接透露金额档 |
| 同一需求跨页一致性（3.5m³ / 6 个月，已登录） | **一致**。安贞店 A003：列表（05）、推荐（09）、详情（11）都是 ¥280/月 · 7 折 · 整期 ¥1,680 · 6个月；A004 都是 ¥390/月 · 特价仓 · 整期 ¥2,340；芍药居 B003 两页都是 ¥315 / ¥1,890。未登录三页都是 A003 ¥260/月起、A004 ¥362/月起。算法与规则表相符（400×0.7=280；620×0.9×0.7=390；起价取 6.5 折档） |
| 库存紧张 / 附近满仓 / 全城满仓 | 都有画面、都有出口，但有显示问题（A-12、A-17、A-21、A-22） |
| 大容量（35m³） | 不再阻断，走普通无匹配 + 「可申请专属方案」顾问卡，与 W37 方向一致；演示库存最大 16m³，所以 35m³ 永远落在无匹配，看不到「≥30m³ 正常选仓下单」这一态 |
| 断网 | 首页保留顶栏，有「重新加载」（rv33）。其他页的失败 / 断网态无图 |

**主路径没有走不通的地方。** 下面的问题集中在三类：已裁规则没落地（A-01）、几个租后异常场景首页不提示（A-02、A-03）、同一信息在不同页写法不同。

## 5. 做得对、不需要改的

1. **未登录不泄露金额**做得干净：价格在取数层就按登录态分叉，未登录的数据对象里根本没有整期金额和价差，不是靠模板隐藏；顾问卡未登录只按容量判定。
2. **同一需求跨页数字一致**：列表、推荐、详情共用 `finder.line`，3.5m³ / 6 个月在三页的容量、月价、折扣标签、整期金额逐项相同；特价仓「九折再乘租期折扣」、起价取最低档并进位、满额减档位都与规则表对得上。
3. **返回路径处理得细**：填容量提交用 `redirectTo`，从推荐页点「修改」回来用 `navigateBack`，不会叠出重复页面；无需求直达推荐页会被带去填容量。
4. **登录守卫**按 D-198 做全了：未登录点下单在当前页开登录层，直达受限页重定向到落点并提示「请登录」，登录成功留在原页刷新出整期价。
5. **下单前复查库存**：推荐页和详情页点「立即下单」时再取一次库存，仓位刚被租走就留在原页提示「所选仓位已售出」，不带着失效仓位进确认订单。
