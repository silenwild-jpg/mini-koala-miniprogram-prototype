# R13-01：未认证企业不可新增企业抬头（2026-11-21，北京时间）

口径：张坤 2026-11-21 群内原话「未认证企业不可新增企业抬头」。补答 R-13，关闭问题单 D-04 与待裁项 PR-136。

## 改了什么
- 规则：`core/account.js canAddCompanyTitle(认证状态)`，只有 `verified` 为真。
- 开票抬头页：企业认证没通过时，新增表单默认「个人」，「企业」置灰，点击提示；下方一条说明带入口，按认证状态换说法（去企业认证 / 查看认证进度 / 查看未通过原因）。
- 接口（演示适配器）：未认证时新增企业抬头、或把个人抬头改成企业类型，返回 `FORBIDDEN`（`reason: CERT_REQUIRED`）。正式接口需同样拦。
- 演示数据：没通过认证的演示账户起始只带个人抬头；「企业已认证」场景仍带企业 + 个人两条。

## 我先定的（已登记 PR-162～PR-164）
- 认证前已存在的企业抬头仍可编辑、删除、设为默认（原话只说「新增」）。
- 说明与提示文案自写。
- 订单的单笔发票页仍可选「企业」并手填企业名称与税号，没有按认证拦（见下）。

## 待业务确认
- **单笔发票页的企业类型要不要也按认证拦？** 现在未认证用户不能存企业抬头，但申请单笔发票时可以直接手填企业名称和税号开企业发票。两处口径是否一致请定。

单元测试 336/336；静态检查 0 错误；页面模拟 36 页、7162 次调用、0 异常；订单冒烟 6 单、1050 次调用、0 异常。没有在微信开发者工具或真机上看过。

2. 说明条在审核中 / 未通过两种状态下，链接换行后的位置。
