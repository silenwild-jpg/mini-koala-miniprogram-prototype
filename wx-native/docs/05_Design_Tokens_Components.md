## 4. 三组必须共用的组件
1. 需求卡：首页、「我的」、找仓进度。
2. 订单摘要卡 + 费用明细：确认订单、订单详情、订单列表、续租 / 退仓 / 押金 / 发票。
3. 需求表单段：填容量页与各处「修改需求」弹层。

## 5. 微信里要注意的
- 没有 `:root`，变量挂 `page`；弹层如果渲染在 `page` 之外（如 `root-portal`）要确认变量能继承。
- 设计稿用了 `position: fixed` 的底部操作栏和底部弹层，都要加底部安全区。
- 设计稿的图标是内联 SVG 并继承文字颜色。小程序的 `image` 组件显示 SVG 文件时不会继承文字颜色（按我掌握的情况，没有核对文档），所以同一个图标的不同颜色要么导出多份，要么转成字体图标。图标包见 `06_assets/icons/`。
- 横滑的首页推荐轨、长页面里的吸顶页签，按真机验收清单逐项看。
