# 原型成熟度评审与演示判断（W27，2026-11-18）

评审对象：W27 设计稿工作树（34 个页面 / 视图、580 个状态），以及它和仓库 Web 原型（PR #220 `1d0dc7f`）、微信小程序三者之间的关系。
依据：本轮全站回归 1,160 次、全站界面文字 2,524 条、30 个主路径状态的逐按钮点击审计、D-01～D-193 台账。没有线上数据，没有真机。

## 1. 结论

**现在手里是三样不同的东西，成熟度差别很大：**

| 资产 | 是什么 | 现状 |
|---|---|---|
| 设计稿（W27） | 新视觉、新规则的逐状态画面，浏览器里打开 | 画面和规则基本齐；**大多数按钮点了没有反应** |
| 仓库 Web 原型 | 能点通的 HTML 原型 | 仍是 11-14 的旧视觉和旧规则；W1～W27 的改动一行都没进去 |
| 微信小程序 | 体验版的目标形态 | 没有开始；仓库 README 也写明现有代码不是微信原生代码 |

**是否达到演示要求，取决于演示方式：**

| 演示方式 | 判断 | 说明 |
|---|---|---|
| 有人讲解、逐屏展示（内部评审、向业务和管理层汇报、给开发讲需求） | **达到** | 用本轮新增的 `design/demo.html`，10 条路径 104 个画面按顺序打开 |
| 把链接发给对方自己点着体验 | **未达到** | 主按钮没有反应，对方会卡在第二步 |
| 在微信里扫码体验 | **未达到** | 这是下一阶段要做的事 |

## 3. 点击审计（本轮新做）

在 30 个主路径状态上，把每个可见的链接和按钮各点一次，看有没有跳转或页面变化。此前各轮只核对过「链接有没有目标页」。

| 结果 | 数量 | 说明 |
|---|---|---|
| 链接可跳转 | 162 | 底部导航、首页入口卡、「我的」各入口、订单卡、协议链接等 |
| 拨打电话 | 3 | 联系门店 |
| 点了有反应 | 6 | 一键开锁提示、取消订单弹窗、提交退仓确认弹窗 |
| 点了没有反应 | 312 | 其中 140 个是物品页的加减和规格按钮 |
| 合计 | 483 | |

没有反应的包括主流程上的每一个主按钮：查看仓位报价、查看推荐仓位、立即下单、查看报价（登录）、下一步：确认订单、签署并提交、预约用仓、提交续租需求、确认并支付、提交发票申请，以及所有页面的「返回上一步」。租期选择、筛选、排序、收藏、地图导航也没有反应。

也就是说：设计稿能从首页走到各个入口页，但走不进任何一条流程的第二步。每个状态要靠地址打开，这也是我做演示导航的原因。

局限：只点了 30 个状态（共 580 个），每个按钮只点一次、等 0.35 秒看变化；没有测输入框。

## 4. 演示时建议先说明的 5 件事

1. 画面是逐状态的设计稿，由讲解人切换，不是可操作的产品。
2. 价格、折扣中间档、满额减金额是结构示例，不是定价。
3. 公里数、门店、订单都是演示数据。
4. AI 估算、一键开锁、地图选点、电子签、微信支付是占位或示意，未接入。
5. 协议页是合同原文；界面上的条款短句法务还没有审。

## 5. 要不要先把设计稿做成可点击的

**我的建议是不做。** 把主流程接成可点击要改动多个渲染文件（工作量我没有细估），做出来仍然只是浏览器里的演示；你下一步就是微信体验版，同样的工作量放在小程序里才留得下来。讲解式演示现在已经够用。

如果近期有「必须发给对方自己点」的演示，再说，我只接「估算 → 找仓 → 下单 → 支付成功」这一条。

## 6. 冻结时带着走的已知问题

不影响冻结，但进了体验版会被看到，按是否需要别人提供分两类。

**设计侧知道、暂不处理的**
- 订单详情「租用中」一屏有两个「一键开锁」（你裁过不让给入仓指引，D-175）。
- 电子合同页没有合同编号、下载，也没有加载、失败、断网三态。
- 无门店城市时「距离」筛选和排序没处理；用户手动选到无门店城市没画。
- 续租沿用原折扣的待支付、支付失败状态没单独画（版式与普通续租相同）。
- 组合仓在未登录下的起价、组合仓仓位卡第二行没有渲染核对过。
- 提前退仓预计结算的三处算法是我定的（见 W27 报告 §2）。

**等别人提供的**（共 26 项，清单在 W26 的 `02_Pending_Rulings_and_Self_Set_Rules.md` 第三部分，本轮无变化）
- 财务：折扣三档、满额减三档、订单明细与出租率。
- 业务：实际仓位长宽高、增值保障与 E存价格、发票与押金口径、券有效期、逾期补缴、协议版本号与生效日期。
- 法务：隐私指引与政策正文、注销条件、E存部分召回、界面短句。
- 外部：地图 API、开锁设备、第三方电子签、订阅消息模板。
- 你：销售价格权限表审批人；计费面积 × 1.5 的适用范围。
