迷你考拉仓小程序 · 可点击演示版（2026-11-18）

打开方式
- 本地：解压后双击 index.html（建议 Chrome / Edge）。
- 在线：把整个文件夹原样上传到任意静态网站托管（对象存储静态网站、Nginx 目录、内部静态服务器均可），访问 index.html。
  全部是静态文件，不需要后端、数据库和构建步骤；所有路径都是相对路径，可以放在子目录下。
- 电脑上显示手机框和说明栏；手机上只显示小程序画面。
- index.html 已带 noindex；对外发链接前建议在托管侧加访问密码。

内容
- index.html      入口（手机框 + 起点选择）
- demo.html       画面目录，按使用顺序列出 104 屏
- pages/          34 个页面；pages/proto-nav.js 是本版新增的跳转层
- 其余目录        设计稿原有的样式、数据和图片

体验前请知道
- 未登录不能进入确认订单及其后的页面（D-198）：点「立即下单」「下一步」会先出登录层；直接打开这些地址会被带回登录层。
- 价格、折扣中间档、满额减金额是结构示例，不是定价；门店、公里数、订单是演示数据。
- 每个画面的数值是固定的，点加减、换租期、换仓位不会重新计算，会提示「数值固定」。
- 左上角虚线「模拟：…」按钮是演示工具，代替门店报价、验仓、到期等不由用户触发的变化。
- AI 估算、一键开锁、地图、电子签、微信支付、订阅消息未接入，弹窗为示意。
- 这是浏览器网页，不是微信小程序；微信里的授权弹窗、支付、定位表现以体验版真机为准。
